# 大小周工作日规则

> 供定时日报等自动化判定「今天是否上班」。公司正式大小周日历未入库前，以本页锚点为准；人事发放正式日历时更新锚点并登记 [记忆变更日志](记忆变更日志.md)。

## 已确认口径（观点，待正式制度核对）

- 执行大小周；常规作息 9:00—18:00（来源：RAW-20260803-003 制度讲解，待验证）。
- **大周**：周一至周六上班。
- **小周**：周一至周五上班。
- **周日**：休息，不触发工作日日报。

## 自动化锚点（廖送平 2026-08-08 确认）

- **锚点周周一**：`2026-08-03`（该周为 **大周**）。
- **交替规则**：以锚点周一为第 0 周；每 7 天为一档，偶数档（0、2、4…）为大周，奇数档（1、3、5…）为小周。
- **时区**：Asia/Shanghai。

## 判定步骤（Agent / 定时任务）

1. 取上海时区「今天」；若为周日 → **非上班日**，跳过日报。
2. 求「本周一」日期 `weekMonday`（ISO 周，周一为一周起点）。
3. `weeksSinceAnchor = floor((weekMonday - 2026-08-03) / 7 天)`（整周数，可为负）。
4. 若 `weeksSinceAnchor % 2 === 0` → **大周**（周一—周六）；否则 → **小周**（周一—周五）。
5. 若今天为周六且当前为小周 → **非上班日**，跳过日报。
