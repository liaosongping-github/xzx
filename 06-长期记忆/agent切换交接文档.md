# agent切换交接文档

> 跨 Agent（Cursor / Codex 等）切换时的权威交接页。新 Agent 先读本页，再按链接进入工作台与长期记忆；不要依赖未入库聊天或 Agent 私有记忆。

## 当前阶段目标

- 入职业务与系统熟悉期：优先跑通双引鲸 ERP 贸易主流程；MRP 仅背景了解。
- 建立可追溯的产品工作体系；Raw 消化由**当前会话 Agent**执行（`digest-engine.json` → `session-agent`）。
- 可视化工作台 MVP 已落地；第二阶段再改消化提示词，强制知识落库先进待确认区。
- 个人 Skill：权威源 `.agents/skills` + Junction 同步 Cursor/Codex（见协作偏好）。
- **双引鲸高保真原型**须遵循 [设计规范/双引鲸](../03-产品工作/设计规范/双引鲸/README.md)，并引用 [组件库](../03-产品工作/设计规范/双引鲸/组件/README.md)。
