# 模板说明

复制模板后，应立即替换占位符并更新文件名、编号和日期。

## YAML 常用字段

| 字段 | 中文含义 | 示例 |
|---|---|---|
| `id` | 稳定编号 | `REQ-20260803-001` |
| `title` | 标题 | `登录流程优化` |
| `type` | 文档类型 | `requirement` |
| `status` | 当前状态 | `待澄清` |
| `owner` | 负责人 | `廖送平` |
| `product` | 所属产品 | `用户中心` |
| `business_domain` | 业务域 | `账户体系` |
| `created` | 创建日期 | `2026-08-03` |
| `updated` | 更新日期 | `2026-08-03` |
| `last_verified` | 最后验证日期 | `2026-08-03` |
| `source` | 信息来源 | `访谈/制度/系统` |
| `related` | 关联文档 | 相对链接列表 |
| `tags` | 标签 | `[登录, 用户体验]` |
| `confidentiality` | 保密级别 | `internal` |
