# 现网页面复刻

## 何时用

要把贸易端现网复刻成可操作的本地 HTML 原型，并顺带抽出可复用组件、校准设计规范时使用。

## 输入

- 阶段：`阶段1`（默认）或 `阶段2`
- 现网入口：`https://trade.tsbsoft.com`（凭据只用本机 `08-自动化/.runtime/`，禁止写入知识库/聊天）

## 提示词正文

你要把双引鲸**贸易端现网**复刻成一份可本地打开的高保真 HTML 原型。验收标准不是「长得像」，而是**操作路径与现网一致**：菜单跳转、多页签、查询（含过滤结果）、弹窗/抽屉、字段、行操作、分页，点下去都要有对应界面。数据用静态演示数据即可，禁止调现网写接口、禁止保存/删除真实数据。

上次失败（已删除的 `03-产品工作/现网页面复刻/`）：只做出列表壳，查询/弹窗/跳转是假的。本次禁止再交「能看不能点」的页。

### 权威与对照

1. **现网实装是唯一标准。** 每页必须登录后打开对应路由，对照 DOM/截图再画，禁止凭记忆或旧模板补字段。
2. 原型样式以 [设计规范/双引鲸](../03-产品工作/设计规范/双引鲸/README.md) 的 `tokens.css`、`shell.css`、`components.css` 和 [组件库](../03-产品工作/设计规范/双引鲸/组件/README.md) 为起点，但**规范必须服从现网**：
   - 色、字号、间距、圆角、布局、交互与现网不一致 → **改规范**（改 token / shell / components / 组件片段 / 对应说明），不要为了迁就旧规范去改原型，也不要只在 README 记一笔差异就放过。
   - 现网有、规范没有 → **补规范**（新 token、新组件、新页面模式或证据编号）。
   - 规范有、现网没有 → 标为过时并改掉，禁止继续画进复刻原型。
3. 现有组件可引用，必须先对照现网；不够就新增。禁止为了套旧组件而减交互。
4. 菜单以现网侧栏为准（含「数据分析」）。历史 [菜单树](../02-业务知识库/系统与流程/双引鲸ERP/07-菜单树.md) 只作索引，过期以现网为准。

改规范时同步更新：`设计与交互规范.md`、相关 `页面模式/`、`组件/*.md`、`证据与待确认.md`（补现网对照证据）。根 README 只写「本阶段改过哪些规范文件」，不把「跟现网的差异清单」当成长期口径。

### 落盘（禁止写到别处）

根目录：`03-产品工作/现网页面复刻原型/`

```
03-产品工作/现网页面复刻原型/
  README.md                 # 怎么打开、阶段状态、本阶段改过的规范文件
  index.html                # 入口，默认进首页
  组件/
    README.md               # 公共 vs 特有；怎么引用
    snippets/               # 可复制片段
  页面/
    首页/
    产品管理-产品资料/
    …                       # 阶段2 再按菜单加
  数据/                     # 静态 JSON；敏感数据脱敏
```

打开方式：本地静态即可（相对路径）。全页必须能从侧栏互相跳转，不要做成互不相干的单页。

公共组件双写：

- 复刻目录 `现网页面复刻原型/组件/`（给本原型引用）
- 同时更新 `03-产品工作/设计规范/双引鲸/组件/`（给后续画需求用）

两处职责保持一致，禁止只改一边。

### 保真范围（必须做 / 明确不做）

**必须做成可点、可演示：**

- 侧栏展开/收起、一级二级菜单、打开页签、页签切换/关闭
- 顶栏「菜单查询」可按名称过滤菜单（静态）
- 列表：状态页签、快捷查询、查询/重置、综合查询、列显示、排序入口、分页、行内操作
- 弹窗/抽屉：打开、关闭（右上 × / 取消/关闭）、底栏按钮、分区锚点
- 查询：用静态数据过滤，查询后表格条数和行要变；空结果要有空态
- 主按钮打开的界面：字段名、控件类型、分组、占位符、底栏文案与现网一致

**允许静态示意、点了给说明即可：**

- 上传/导入的真实解析、打印、公式计算、权限矩阵、虚拟滚动性能
- 确定/保存/删除：弹确认或成功提示，改本地静态数据；禁止请求现网写接口

**禁止：**

- 用设计规范模板页冒充现网页（缺字段、假按钮、点了没反应）
- 发现规范与现网不一致却不改规范
- 把密码、token 写入仓库
- 一次画完全站却不暂停等确认（阶段1 必须停下）

### 组件封装（边复刻边抽）

每做一个现网控件，先归类再落地：

| 类型 | 判定 | 落点 |
|---|---|---|
| 公共组件 | 至少 2 个页面会用，或属于全局壳 | `现网页面复刻原型/组件/` **且** `设计规范/双引鲸/组件/` |
| 特有组件 | 仅本页/本模块 | 写在该页目录，`组件/README.md` 登记「特有」 |

产品资料试点结束时，至少形成以下可复用或待复用候选（名称可改，职责不能少）：

1. **全局壳**：Logo、侧栏菜单、顶栏（菜单查询/日期天气/消息/用户）、多页签
2. **列表页骨架**：状态页签 + 查询条 + 工具栏 + 表 + 分页
3. **快捷查询条**：关键词 + 若干下拉 + 查询/综合查询
4. **综合查询抽屉**：右侧抽屉，分组表单，重置/确定
5. **数据表**：含勾选、图片列、编号蓝链、右侧固定操作列（编辑/删除/更多）
6. **表格工具簇**：全屏/密度/刷新/导出/列设置等圆形图标
7. **列设置抽屉**
8. **分页**：共 N 条、页大小、页码、前往
9. **居中表单弹窗**：宽版 + 左侧分组锚点 + 底栏（如保存草稿/关闭/确定）
10. **确认框**：删除等二次确认

特有（产品资料试点先登记，不硬塞进公共库）：产品资料「图搜」、选品车、行更多里的业务项（如加入选品车/留痕记录/货柜箱计算）等。

组件必须可被后续原型用相对路径引用，禁止每页复制一套侧栏 HTML 后不再维护。试点期的“公共”指全局壳或已验证可跨页复用的结构；仅产品资料使用的能力登记为特有，待第二页验证后再提升为公共组件。

### 阶段1：产品资料单页试点（做完即停，等我确认）

只交付 **产品管理 / 产品资料**，**不要**制作首页或其他菜单的正式复刻页。默认选它做试点，是因为该页可以一次验证壳层、列表、查询、抽屉、弹窗、行操作和本地数据链路；它不代表已完成整个产品管理模块。

**产品管理 / 产品资料** `https://trade.tsbsoft.com/tsProductInformation`

现网结构（2026-09-10 对照，仍须当场复核）：

- 侧栏：产品管理展开，「产品资料」高亮；顶栏多页签出现「产品资料」
- 状态页签：草稿产品 / 单个产品 / 组合产品 / 客户专属 / 全部；切换后表格数据按静态规则变
- 快捷查询：关键词「请输入」；是否有图（全部/是/否）；是否停产（全部/是/否）；产品状态（全部/上架/下架，默认上架）；查询、综合查询、图搜
- 工具栏：`+ 新建产品`、导入产品、更多操作；勾选行后现网若出现批量按钮，原型也要出现
- 表：序号、勾选、产品图片、产品编号（蓝链）、辅助编号、产品名称、英文名称、出厂货号、产品类型、出厂价、进货价、第三方价格… 操作列固定：编辑、删除、更多。列集以现网当前账号为准，用列设置开关
- 分页：共 N 条，默认 100 条/页
- **综合查询**：右侧抽屉（现网约 850px），标题「综合查询」；分组：基础信息、产品参数、厂商信息、其他信息；底栏「重置 / 确定」；确定后按静态数据过滤
- **新建产品 / 编辑**：现网是宽幅居中弹窗 + 左侧分组 + 右侧多区表单 + 底栏（保存草稿/关闭/确定）。字段必须现网打开后逐项抄，禁止用旧字段字典凑数
- **图搜、导入、更多操作、行更多、删除确认**：都要能打开对应层；导入不解析真实 Excel

阶段1 交付物：

1. 产品资料可打开的单页试点；从侧栏或本地入口可进入，未实施页面只可作为明确的导航占位
2. `组件/README.md`：公共/特有清单 + 引用方式
3. 根 README：对照了哪些现网路由、本阶段改过哪些规范文件、如何打开
4. 设计规范已按现网改完/补完本阶段用到的壳层与组件
5. 最小可用编辑器：页面/组件树、属性编辑、Schema 校验、预览和本地保存；改标题、查询项、表格列、按钮文案/显隐或已注册 Action 后，运行页必须由同一份 Schema 更新
6. 试点验收记录：现网差异及处理结果、编辑器 Schema Patch 结果、测试结果、待扩展项

完成后**停止**，演示产品资料的关键操作并等用户明确说「产品资料试点确认，可扩展」。未经确认禁止制作首页正式复刻页和阶段2。

最小编辑器不做自由拖拽、组件新增/排序、撤销重做、版本发布、审计日志或 Agent 改页；这些在产品资料试点确认后另行实施。

### 扩展批次1：首页（仅当用户明确确认产品资料试点）

先复刻首页 `https://trade.tsbsoft.com/tsHome`，并复用已确认的全局壳与通用组件；发现首页与试点组件不一致时，先修正规范和组件，不复制产品资料页面结构。

现网结构（2026-09-10 对照，仍须当场复核）：

- 同一套全局壳；侧栏当前是「首页」
- 工作台快捷入口：产品资料、选品中心、独立站点、客户资料、销售报价、客户发货 → 点击走现网同款跳转；未实施目标页可做有壳、有标题的占位页
- 订单统计（近30天 + 日期范围 + 图）
- 待办事项（列表 +「查看全部」）
- 商品销量排名表
- 下单客户统计 / 采购厂商统计（页签切换）

完成首页后，更新试点结论、组件清单和 E2E；由用户决定继续逐模块复刻或暂停调整。

### 阶段2（仅当用户明确说「产品资料试点确认，可扩展；开始全量」）

按现网侧栏全部叶子菜单铺开，默认包含：小竹熊选品、系统管理、数据分析。登录页、权限配置细节、打印模板编辑器不做，除非用户另说。

每一页仍是：先打开现网 → 抄结构/字段/弹窗 → 再画 → 能点。公共组件只扩库、不重画壳。规范继续跟现网校准。每完成一个一级模块可暂停汇报，不要闷头一次交 50 页无法验收。

### 工作方法

1. 用本机已有登录方式打开现网；只读点击；截图可作对照，以 DOM 字段为准。
2. 先壳后页：先打通产品资料所需的全局壳和页面交互；首页仅在产品资料试点确认后实施。
3. 先抄现网，再封装组件，再回写规范：不要先发明组件再削现网去迁就。
4. 演示数据 10～30 行够用来点查询/分页/页签；编号、名称用假数据。
5. 产品资料试点交付前用浏览器自己点一遍：本地入口→产品资料→查一条→综合查询→新建→编辑→删除确认→图搜/导入/更多操作层。任一步没界面就不算过。
