# REQ-20260812-001 V1 数据报表基座 · 设计草案

> 来源：2026-08-12 Superpowers brainstorming 澄清（廖送平确认三节设计）。  
> 交付顺序：**澄清 → 原型 → PRD**（本草案确认后先出原型，不先写 PRD 正文）。  
> 信息分级：已确认需求口径（本会话）；字段明细以各单据字段字典（待验证）为准。

## 1. 目标与成功标准

**目标**

- 在双引鲸内为业务提供五张单据的**产品明细行**级查询与导出，便于自行加工。
- 先搭「可查可导」的数据基座，不做汇总看板与跨单分析。

**成功标准（V1）**

- 侧栏可进入「数据报表」及五个子报表页。
- 每页按明细行展示，筛选灵活，默认可导出当前筛选结果或勾选行。
- 可从报表明细跳回原单据；角色仅通过菜单 +「导出」功能权限控制访问。

## 2. 方案选型

采用 **共用报表壳 + 五套单据配置**：

- 统一交互：筛选、字段显隐、分页、导出、跳转。
- 每张报表只配置：数据源单据、筛选项、列（表头+明细）、详情跳转路由。

不采用：薄封装现有列表接口硬凑明细（易撞边界）；也不采用 V1 离线宽表。

## 3. 菜单与权限

### 3.1 菜单

| 层级 | 名称 | 说明 |
|---|---|---|
| 一级 | 数据报表 | 排在「财务管理」下方 |
| 二级 | 报价数据报表 | 销售报价单 · 产品明细行 |
| 二级 | 销售数据报表 | 销售订货单 · 产品明细行 |
| 二级 | 采购数据报表 | 采购订货单 · 产品明细行 |
| 二级 | 查货数据报表 | 收货单 · 产品明细行 |
| 二级 | 出货数据报表 | 客户发货单 · 产品明细行 |

### 3.2 权限（沿用「编辑角色 → PC菜单权限」）

- **菜单权限**：控制一级/二级是否可见（有页面访问权即可查询、字段配置）。
- **功能权限**：每个二级仅增加 **「导出」**；无导出权则隐藏或禁用导出。
- **不做**：数据权限（行级按业务员/客户等隔离）；查询、字段配置不单独做功能权限点。
- APP 菜单权限可后补，不阻塞 PC V1。

## 4. 页面交互（五页共用）

**布局**：筛选区（可折叠）→ 操作栏（查询 / 重置 / 字段配置 / 导出）→ 明细表 → 分页。

**筛选**

- 对齐对应单据列表页已有条件，并尽量丰富灵活。
- 日期：支持多种日期类型（单据日期 / 创建日期 / 审核日期等，以该单实际字段为准），每种可设起止；不做同一类型多段 OR。
- 状态：多选；**默认**仅「有效/已审核」类；作废、草稿需用户手动勾选后才纳入。

**列表与字段**

- 一行 = 一张单据内一条产品明细；表头字段随行重复带出。
- 列对齐该单详情的表头 + 明细字段；字段配置仅显隐（及现网若已有的列顺序）。
- 支持行勾选。

**导出**

- 需「导出」权限。
- 按当前筛选结果导出全部命中明细行（不受当前分页限制）。
- 同时支持仅导出勾选行。
- 导出列 = 当前字段配置显隐后的列。
- 文件格式与系统现有导出（如 Excel）保持一致。

**跳转**

- 点击单据号（或约定行区域）打开对应原单据详情/编辑页。

**不做（交互）**

- 报表内编辑、审批；汇总图/看板；跨单据联表。

## 5. 五表数据口径

| 子菜单 | 数据源 | 行粒度 | 筛选/字段基准 |

| 报价数据报表 | 销售报价单 | 报价明细行 | 该单列表筛选 + 详情表头/明细 |
| 销售数据报表 | 销售订货单 | 订货明细行 | 同上 |
| 采购数据报表 | 采购订货单 | 采购明细行 | 同上 |
| 查货数据报表 | 收货单 | 收货明细行 | 同上 |
| 出货数据报表 | 客户发货单 | 发货明细行 | 同上 |

## 6. V1 非目标

- 数据权限 / 行级隔离
- 汇总看板、图表、跨单联表分析
- 择样 / 选品 / 站点等多入口报价并入报价报表
- 销售出库单、应收应付等未列入的五单之外单据
- APP 端报表（可后补）
