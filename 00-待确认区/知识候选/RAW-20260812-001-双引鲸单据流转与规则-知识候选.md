# 知识候选：双引鲸单据流转与业务规则

> 来源：郭强总发给廖送平理解学习的流程图+规则图（RAW-20260812-001）。**全部为待验证口径**，确认前不得写入已验证事实。

## 拟写入摘要

### 1. 更新 `05-单据主链路.md`（待验证）

在现有「候选主干」上补充/对齐：

**报价→订单入口（补充）**

- 销售报价、展厅择样、小竹熊选品报价、站点报价单 → 销售订单。
- 报价→订单默认带数；订单生成后可手工改，图称不做数据限制校验。
- 报价单无上下游锁定：即使已生成订单，报价仍可改。
- 订单可独立新建；生成时可展示库存仅参考。

**销售订单改单约束（补充）**

- 有下游后：客户、报价信息不可改。
- 出货前：产品可增删。
- 数量：可改；已出货后不得小于已出货量；等于已出货量时提示结单。
- 已生成应收后：报价公式不可改。
- 厂商信息可否修改：图中 3.4 存疑，落库时标「未知」。

**采购支路（补充）**

- 一键采购：按销售订单厂商汇总自动生成并可按厂商分拆；支持同厂商多销售单合并；默认未完结数量可改；改厂商时提示是否同步。
- 按需采购 / 备货采购（备货为图中虚线，边界待确认）。
- 查货收货：收货量 ≤ 采购量；收齐时可提示更新采购入库并完结查货。
- 收货后：厂商锁定；采购数量 ≥ 已收数量。
- 一键入库：入库量 ≤ 查货量。
- 采购应付：应付量 ≤ 查货量；生成应付后查货单厂商不可改。
- 采购收货可一键直连客户出货。

**出货/结算支路（补充）**

- 一键出货计划（默认本销售单未完结，可加客户未完结）→ 出货/排柜计划 → 客户出货。
- 或销售订单一键直接客户出货（默认该客户未完结）。
- 一键出库 → 订单出库；一键客户应收（默认未完结并自动扣减）。

**通用规则（补充）**

- 流转默认带「未完结」数据，允许手工录入/调整。
