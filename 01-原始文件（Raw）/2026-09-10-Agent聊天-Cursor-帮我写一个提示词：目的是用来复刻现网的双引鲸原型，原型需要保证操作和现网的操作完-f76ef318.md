### 权威与对照

1. **现网实装**是唯一结构/交互权威。每页必须登录后打开对应路由，对照 DOM/截图再画，禁止凭记忆或旧模板补字段。
2. 视觉跟 [设计规范/双引鲸](03-产品工作/设计规范/双引鲸/README.md)：`tokens.css`、`shell.css`、`components.css`。与现网冲突时跟现网，并在 README 写差异。
3. 现有 [组件库](03-产品工作/设计规范/双引鲸/组件/README.md) 可引用，但必须先对照现网；不够就新增，禁止为了套组件而减交互。
4. 菜单以现网侧栏为准（含「数据分析」）。历史 [菜单树](02-业务知识库/系统与流程/双引鲸ERP/07-菜单树.md) 只作索引，过期以现网为准。

### 保真范围（必须做 / 明确不做）

**必须做成可点、可演示：**

- 侧栏展开/收起、一级二级菜单、打开页签、页签切换/关闭
- 顶栏「菜单查询」可按名称过滤菜单（静态）
- 列表：状态页签、快捷查询、查询/重置、综合查询、列显示、排序入口、分页、行内操作
- 弹窗/抽屉：打开、关闭（右上 × / 取消/关闭）、底栏按钮、分区锚点
- 查询：用静态数据过滤，查询后表格条数和行要变；空结果要有空态
- 主按钮打开的界面：字段名、控件类型、分组、占位符、底栏文案与现网一致

**允许静态示意、点了给说明即可：**

- 上传/导入的真实解析、打印、公式计算、权限矩阵、虚拟滚动性能
- 确定/保存/删除：弹确认或成功提示，改本地静态数据；禁止请求现网写接口

**禁止：**

- 用设计规范模板页冒充现网页（缺字段、假按钮、点了没反应）

### 保真范围（必须做 / 明确不做）

**必须做成可点、可演示：**

- 侧栏展开/收起、一级二级菜单、打开页签、页签切换/关闭
- 顶栏「菜单查询」可按名称过滤菜单（静态）
- 列表：状态页签、快捷查询、查询/重置、综合查询、列显示、排序入口、分页、行内操作
- 弹窗/抽屉：打开、关闭（右上 × / 取消/关闭）、底栏按钮、分区锚点
- 查询：用静态数据过滤，查询后表格条数和行要变；空结果要有空态
- 主按钮打开的界面：字段名、控件类型、分组、占位符、底栏文案与现网一致

**允许静态示意、点了给说明即可：**

- 上传/导入的真实解析、打印、公式计算、权限矩阵、虚拟滚动性能
- 确定/保存/删除：弹确认或成功提示，改本地静态数据；禁止请求现网写接口

**禁止：**

- 用设计规范模板页冒充现网页（缺字段、假按钮、点了没反应）
- 发现规范与现网不一致却不改规范
- 把密码、token 写入仓库
- 一次画完全站却不暂停等确认（阶段1 必须停下）

### 组件封装（边复刻边抽）

每做一个现网控件，先归类再落地：

| 类型 | 判定 | 落点 |
|---|---|---|
| 公共组件 | 至少 2 个页面会用，或属于全局壳 | `现网页面复刻原型/组件/` **且** `设计规范/双引鲸/组件/` |
| 特有组件 | 仅本页/本模块 | 写在该页目录，`组件/README.md` 登记「特有」 |

阶段1 结束时，至少沉淀这些公共件（名称可改，职责不能少）：

1. **全局壳**：Logo、侧栏菜单、顶栏（菜单查询/日期天气/消息/用户）、多页签
2. **列表页骨架**：状态页签 + 查询条 + 工具栏 + 表 + 分页
3. **快捷查询条**：关键词 + 若干下拉 + 查询/综合查询
4. **综合查询抽屉**：右侧抽屉，分组表单，重置/确定
5. **数据表**：含勾选、图片列、编号蓝链、右侧固定操作列（编辑/删除/更多）
6. **表格工具簇**：全屏/密度/刷新/导出/列设置等圆形图标
7. **列设置抽屉**
8. **分页**：共 N 条、页大小、页码、前往
9. **居中表单弹窗**：宽版 + 左侧分组锚点 + 底栏（如保存草稿/关闭/确定）
10. **确认框**：删除等二次确认

特有（阶段1 先登记，不硬塞进公共库）：产品资料「图搜」、选品车、行更多里的业务项（如加入选品车/留痕记录/货柜箱计算）等。

组件必须可被后续原型用相对路径引用，禁止每页复制一套侧栏 HTML 后不再维护。
