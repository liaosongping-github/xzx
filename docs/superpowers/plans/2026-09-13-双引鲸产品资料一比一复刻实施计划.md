# 双引鲸产品资料一比一复刻 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不请求现网写接口的前提下，以当次只读证据为准，交付字段、默认值、弹层和可观察交互均可本地复现的产品资料试点页。

**Architecture:** 现网证据由人工登录后的 Playwright 只读脚本采集；`ProductInformationPage` 使用同一份 PageSchema、Registry 与 Mock 状态渲染。查询、页签、分页、表单和确认层通过 Action Registry 定义的受控本地状态变更，不创建第二份页面结构数据。

**Tech Stack:** React 19、TypeScript、Vite、Vitest、Testing Library、Playwright 1.62。

**Spec:** `docs/superpowers/specs/2026-09-13-双引鲸产品资料一比一复刻设计.md`

## Global Constraints

- 现网只允许读取、截图、DOM/样式观察；不得提交、保存、删除或调用写接口。
- 不保存账号、密码、Cookie、token 或现网业务数据；Mock 数据必须脱敏。
- 未在当次现网证据中出现的字段、默认值或规则必须登记为未知，不得伪造。
- 每个功能先写失败测试并观察失败，再实现最小代码。
- 每完成一个独立任务运行测试、构建、`git diff --check` 并中文提交。
- 产品资料试点未经“产品资料试点确认，可扩展”不得制作首页或其他业务页面。

- [ ] **Step 3: 实现脱敏记录、筛选和分页纯函数**

```ts
export type ProductRecord = { id: string; tab: ProductTab; productCode: string; name: string; hasImage: boolean; discontinued: boolean; status: '上架' | '下架'; [column: string]: string | boolean };
export function filterProducts(records: ProductRecord[], filters: ProductFilters) {
  return records.filter((record) => (filters.tab === '全部' || record.tab === filters.tab)
    && (!filters.keyword || `${record.productCode} ${record.name}`.includes(filters.keyword))
    && (filters.hasImage === '全部' || record.hasImage === (filters.hasImage === '是'))
    && (filters.discontinued === '全部' || record.discontinued === (filters.discontinued === '是'))
    && (filters.status === '全部' || record.status === filters.status));
}
```

将 Registry 的 `data-product-information.mockData` 改为该模块导出的脱敏记录，不保留现网客户/产品数据。
