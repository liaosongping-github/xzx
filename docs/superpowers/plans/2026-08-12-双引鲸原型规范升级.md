# 双引鲸原型规范升级 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将双引鲸设计规范升级为以现网证据驱动、面向 Agent 生成高保真 HTML 原型的轻量规范。

**Architecture:** 保留 README、Token、壳层、模板与交付清单的既有主链路；新增证据台账和按页面类型拆分的使用说明。规范只定义已观察到的双引鲸页面组合与视觉约束，不重复实现 Element Plus 或 vxe-table 的组件契约。

**Tech Stack:** Markdown、CSS、静态 HTML；Element Plus 与 vxe-table v4 官方文档作为正式实现的组件参考。

## Global Constraints

- 服务对象为 Agent 的高保真 HTML 原型，不作为研发前端实现规范。
- 现网截图优先，摹客仅补交互；未验证内容不得表述为已验证事实。
- 不新增依赖，不修改业务知识库事实。
- 页面模板必须继续通过 `../shell.css` 引用共享壳层。
