# 产品资料证据优先视觉重建计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (\`- [ ]\`) syntax for tracking.

**Goal:** 将产品资料页从功能演示改为以现网截图为准的逐状态高保真原型。

**Architecture:** 每个状态以同一浏览器、1920 × 875 视口下的现网截图和可访问 DOM 为唯一输入；本地只使用脱敏 Mock 替代记录值。页面实现按全局壳、默认列表首屏、单一浮层三个层级拆分，任何后续状态都不得破坏已经通过截图对照的首屏。

**Tech Stack:** React、TypeScript、Vite、Vitest、Testing Library、现有双引鲸 tokens 与 shell/components CSS。

**Spec:** [总实施计划](2026-09-10-双引鲸可视化原型复刻与Agent协同平台-总实施计划.md)

## Global Constraints

- 现网仅可只读观察；不得提交、删除、上传、导出或改变账号配置。
- 每个状态固定 1920 × 875 视口，先保存截图与 DOM 摘要，再写本地实现。
- Mock 数据必须脱敏；不得复制现网真实产品、客户或账号数据。
- 视觉验收看截图结构、间距、尺寸和层级，不以“测试通过”替代。
- 不自动 push；每个独立可还原改动使用中文说明单独提交。
