# 交互清单

## 跨页基础交互

- 侧栏展开/收起、一级/二级菜单跳转、顶栏菜单名称过滤。
- 多页签打开、切换与关闭。
- 首页快捷入口进入产品资料；其余未实施入口仅到阶段 2 占位页。

## 产品资料交互

| Action 类型 | 已观察入口 | 阶段 1 Mock 行为 |
|---|---|---|
| `switchTab` | 草稿产品、单个产品、组合产品、客户专属、全部 | 切换静态数据集 |
| `query` / `reset` | 关键词、是否有图、是否停产、产品状态 | 过滤列表并呈现空态 |
| `openModal` | 综合查询、列设置 | 打开对应弹窗；综合查询分为基础信息、产品参数、厂商信息、其他信息，列设置可见关闭/保存等动作；结果行为待复核 |
| `openModal` | 新建产品 | 打开七分区表单，底部提供保存草稿、关闭、确定；控件启用和提交行为待复核 |
| `openModal` | 编辑 | 打开预填七分区表单，底部提供关闭、确定；字段可编辑范围与提交行为待复核 |
| `openDialog` | 删除 | 打开“您确定要删除吗？”二次确认并提示影响条数；本轮仅验证取消返回，确认执行结果待复核 |
| `openFeature` | 图搜 | 显示图片网址、JPG/PNG 上传、Excel 上传和粘贴图片入口；关闭与检索结果待复核 |
| `openFeature` | 更多、行更多 | 菜单项已取证，点击页面空白处关闭；不处理真实文件或请求 |
| `openFeature` | 导入 | 当前点击未出现可观察层，待复核 |
| `paginate` | 分页 | 更新本地页码和可见记录 |

## 验收路径

`首页 → 产品资料 → 快捷查询 → 综合查询 → 新建 → 编辑 → 删除确认 → 返回首页`。

每个 Action 必须在 Action Registry 定义参数校验；尚未实测的现网业务结果不能冒充现网规则。
