## 阶段 1 占位页

首页快捷入口指向但本阶段不实施的页面，可显示同一全局壳、页面标题和“阶段 2”提示；不得伪造其业务功能。

产品资料以外的全量菜单（含选品、系统管理和数据分析）属于阶段 2，必须在阶段 1 验收后另行展开。

## 证据使用原则

- “存在某入口/字段”的界面观察，可作为复刻 UI 的证据。
- 未点击或未保存的行为，不能推断其业务规则；按 Mock 演示行为实现，并在测试与文档中注明。
- 数据定义、权限、状态关系继续以 [双引鲸待确认问题](../../02-业务知识库/系统与流程/双引鲸ERP/04-待确认问题.md) 为准。
