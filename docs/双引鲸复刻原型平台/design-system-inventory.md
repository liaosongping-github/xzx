# 设计系统清单

## 权威来源

1. 现网实装与已验证截图。
2. [双引鲸设计规范](../../03-产品工作/设计规范/双引鲸/README.md)：token、壳层、组件、页面模式、证据台账和交付检查。
3. 摹客仅用于补充交互参考；冲突时不覆盖现网。

## 可迁移的设计资产

- 色彩、字号、间距、圆角、阴影：`tokens.css`。
- 侧栏、顶栏、页签、内容区：`shell.css`。
- 表单、表格、弹窗、抽屉附加样式：`components.css`。
- 首页、列表、详情、表单弹窗、状态异常：`页面模式/`。

## 阶段 1 规则

- 运行时设计 Registry 的初始 token 与上述 CSS 变量保持同名映射；避免再维护一套硬编码颜色和间距。
- 每次现网复核若发现差异，先更新规范与证据台账，再更新原型组件。
- 页面字段、按钮、弹窗与状态依据目标页观察；无法验证的内容显式标为 Mock 演示。
