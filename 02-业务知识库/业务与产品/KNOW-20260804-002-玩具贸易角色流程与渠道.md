# KNOW-20260804-002 玩具贸易角色、流程与渠道

## 一句话说明

课程从贸易公司视角介绍了源头工厂、贸易商、客户、渠道和服务商之间的协作关系，以及从新品放样、报价、PO、排产、QC、装柜到换单和返单的简化贸易链路。

> 本条目是课程业务认知的结构化版本，不等同于公司正式制度、完整国际贸易流程或双引鲸 ERP 的已验证实现。

## 行业参与角色

- F 端：课程内部口径，指源头工厂。
- B 端：贸易公司、批发商、经销商等组织客户。
- C 端：自然人和最终消费者。
- 贸易公司：连接工厂、海外客户和下游渠道，通过选品、供应链整合、报价及履约等方式获得收益。
- 产业服务平台：连接工厂和贸易公司，提供找货、图搜、文搜、信息展示等服务。

小竹熊定位为 `F2B` 平台：一侧是玩具源头厂家入驻并发布产品，另一侧是玩具贸易公司在平台选品和询价。贸易公司向厂家下采购单的最终金额由双方线下沟通确认，平台不管理该价格数据；课程及廖送平说明将其原因归于价格敏感，以及供需双方对价格数据保密的顾虑。

## 内销、外贸与跨境

- 内销：面向国内市场销售。
- 外贸：通过贸易公司开展跨国订单、供应链整合和批量出货。
- 跨境电商：通过跨境电商平台直接或间接触达海外消费者。
- 国内销售需根据产品是否进入强制认证目录判断是否需要 CCC 认证，并关注中文包装等要求。
- 外销产品需根据目的国、产品品类和客户要求匹配认证、标签及包装语言。

不能简单写成“所有内销玩具都必须 3C 认证”。

## 课程介绍的简化贸易流程

```text
新品放样
→ 贸易公司向客户推介
→ 按需寄样/补样
→ 报价与询价
→ 确认数量、价格、包装、货期和认证
→ 客户下 PO
→ 贸易商向工厂落单
→ 工厂接单并排产
→ QC 查货
→ 粘贴唛头并锁定验货状态
→ 送货
→ 整柜或拼柜
→ 装柜
→ 送达指定码头
→ 换单
→ 结算付款
→ 返单
```

### 前期找货与样品阶段

- 放样：新品尚未批量生产时，工厂将数量有限的新品样品放置到合作贸易公司处，同时告知产品定位、推广规划和最低拿货底价，供贸易公司提前向海外客户推介、询价和验证采购意向。
- 找样：贸易公司根据客户提供的图片、货号或要求寻找对应产品及供应商。
- 寄样：工厂或贸易公司将玩具样品邮寄给合作方或意向客户，供对方查看产品品质、细节、功能和包装，确认是否符合采购需求。
- 补样：此前寄出的样品出现丢失、损坏，或者客户因内部评估、展示等场景需要额外同款样品时，相关主体再次补充寄送样品。

### 报价与订单阶段

- 工厂向贸易公司提供新品资料和最低拿货底价。
- 贸易公司重新整理产品资料，结合人工、汇率、包装、运输等成本向海外客户报价。
- 客户、贸易公司和工厂围绕价格、起订量、数量、包装、货期和认证等条件反复询价、议价。
- PO（Purchase Order）是采购订单。潮汕地区将贸易商取得 PO 后正式向工厂下单的动作俗称为“落单”，代表贸易商与工厂确认订单并启动排产生产。

### 生产、查货与唛头

- 工厂确认接单后进行排产和生产。
- 贸易公司或客户可安排 QC 到工厂查货，核对产品质量、数量、包装和订单要求。
- 唛头是粘贴或印制在货物外箱上的文字、图形及标记，用于识别货物、批次、客户和目的地。
- 课程操作口径：QC 完成验货后，在货物外箱粘贴唛头，表示该箱货物已经完成核验；后续送货阶段原则上不再开箱再次验货，特殊情况除外。特殊情况的处理规则尚未确认。
- “类似快递封口贴纸”仅作为课程中的辅助理解，不作为唛头的唯一通用定义。

### 送货、装柜与换单

- 货期到达后，贸易公司通知工厂将货物送往指定地点或码头。
- 单一工厂货量不足整柜时，可由货代协调多家工厂拼柜。课程以约 68 立方为示例，不作为所有柜型的标准容量。
- 装柜是将完成生产和验收的货物装入集装箱。
- 换单是发货收尾阶段的流程动作：货物送至指定码头后，相关主体完成运输或货权相关单据的交接、转换，所得单据可作为后续结算付款的凭证。
- 换单涉及的具体单据、责任主体、结算条件和系统节点尚待确认。

## 区域市场经验（讲师观点）

- 欧美：偏好色彩鲜明、创新、科技感产品，节日销售特征明显。
- 日韩：关注产品细节、精细程度和包装。
- 印度：课程称手工和节庆类玩具较有代表性。
- 东南亚：关注低价和性价比。
- 中东：课程称高品质、品牌和宗教文化适配较重要。
- 俄罗斯：关注价格与质量的匹配。

这些判断不能替代具体国家的销售数据、认证要求和客户调研。

## 授权区域与渠道规则

- 放货：将获得授权的产品投放至指定授权区域或渠道进行销售。
- 窜货：经销商违反约定，将商品销售至授权范围外的区域或渠道。
- 产品授权具有明确的区域和渠道边界；违规跨区域放货可能构成合同违约，并承担相应责任。
- 控价：课程称品牌方或工厂可能对经销渠道设置价格管理要求；具体规则和适用边界尚未验证。

## FOB 与 EXW

- FOB：卖方在约定装运港完成出口清关，并将货物装上买方指定船舶；货物装船后风险通常转移给买方。海运费、保险费及其他费用边界应以合同约定和适用的 Incoterms 版本为准。
- EXW：卖方在约定地点将货物交由买方处置；后续提货、运输和出口手续通常由买方承担，是否含税以合同为准。

Raw 中“FOB 全包价”和逐字稿中“1 XW”不作为本条目的术语口径。

双引鲸当前未维护 FOB、EXW 等字段；这些属于行业术语，由贸易公司与工厂在线下沟通确认。
