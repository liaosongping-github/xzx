# KNOW-20260804-001 玩具产业结构与发展趋势

## 一句话说明

玩具产业是以研发、设计、生产、销售和服务为核心，向原材料、IP、设备、包装、物流、检测和回收等环节延伸的产业生态；课程认为行业正由儿童娱乐用品向全年龄段、IP 化、智能化和情绪价值载体演进。

> 本条目的业务结论来自培训材料、飞书逐字稿和听课笔记，尚未经过权威产业资料或业务负责人验证，不得直接作为公司正式对外口径。

## 产业发展时间线（课程口径）

| 阶段 | 课程中的演进描述 | 验证状态 |
|---|---|---|
| 1978—1979 | 改革开放初期，澄海通过承接香港玩具加工订单形成产业雏形 | 课程口径，廖送平确认采用 |
| 1980—1999 | 从代工逐步转向自主生产和出口，并出现本土品牌 | 课程口径，廖送平确认采用 |
| 2000—2010 | 获授“中国玩具礼品城”等产业称号，政策支持增强 | 课程口径，廖送平确认采用 |
| 2010—2020 | 与央视动画建立战略合作 | 课程口径，合作主体未细化 |
| 2023 | 扩大产业规模并拓展海外市场 | 课程口径，廖送平确认采用 |
| 2024 | “玩具+文化”双驱动，IP 赋予玩具文化和情绪价值 | 课程口径，廖送平确认采用 |
| 2025 | AI 技术推动玩具由静态产品向可交互伙伴演进 | 课程口径，廖送平确认采用 |

该时间线为课程口径。

## 生产合作模式

| 模式 | 课程定义 | 说明 |
|---|---|---|
| ODM | 原始设计制造商负责产品设计和生产，客户可基于产品进行品牌贴牌或定制 | 逐字稿中的 `ODN` 为识别错误，统一规范为 `ODM` |
| OEM | 委托方提供品牌、设计或生产要求，制造商按要求完成代加工 | 具体知识产权和质量责任以合同为准 |
| OBM | 制造商拥有自主品牌，并参与设计、生产、品牌运营和销售 | 体现生产与品牌销售能力的结合 |

课程中的拉布布、泡泡玛特等案例仅作为讲师举例，具体企业与生产模式的对应关系尚未验证。

## 产业链全景

### 上游及产业配套

- IP 与授权：形象、故事、角色、游戏或品牌授权。
- 原材料：ABS、PP、PE 等塑胶粒子，以及合金、布料、木材、纸材等。
- 配件：五金配件、塑料配件、电子元件。
- 机械设备：注塑机、包装机、螺丝机、喷涂设备等。
- 包装耗材：纸箱、彩盒、说明书及其他包装物。
- 加工协作：注塑、喷漆、组装、包装等加工厂。
- 物流服务：国内物流、国际物流、货代和拼柜服务。
- 设计服务：产品设计、包装设计和产品美工。

### 中游

- 品牌商：负责品牌、IP、产品定位和市场运营。
- 生产商：通过 OEM、ODM、OBM 等模式参与产品制造。
- 课程将生产主体概括为三类：
  - 工贸一体型：同时具备生产和销售能力。
  - 纯生产型：主要承担生产，不具备或不负责销售。
  - 组装型：通常没有自有模具，以零部件组装和包装为主，多为小型家庭作坊。

### 下游

- 线下渠道：商场、玩具专卖店、连锁店、品牌店及娱乐场景。
- 线上渠道：综合电商、跨境电商、短视频及社交平台等。
- 最终面向消费者或下游经销、批发渠道。

## 玩具分类

### 按材质

- 塑胶玩具：课程将澄海视为代表性产业集群。
- 毛绒玩具：课程笔记以扬州为代表。
- 木制玩具：课程笔记以云和为代表。
- 其他：布制、金属、纸质及复合材料玩具。

地域对应关系仅是课程列举，尚未验证是否为完整或当前有效的产业分布。

### 按功能

- 益智玩具。
- 机动玩具。
- 电动玩具。
- 电子玩具。
- 智能玩具。

### 按内容属性

- 动漫/IP 玩具：依托角色、故事、粉丝和品牌认知。
- 非动漫玩具：主要依托玩法、功能和通用审美。

## 技术与需求演进

课程将技术升级概括为“塑料积木到 AI 伙伴”：

- 轻量型：以语音交互、大模型接入等能力为主；课程笔记将主要用户描述为 3—8 岁儿童。
- 增强型：集成视觉、感知、情绪识别等能力；课程笔记以成人陪伴型机器人为典型方向。
- 技术壁垒：通信模组、大模型 API 对接、角色/IP 定义，以及通过 RAG 等方式定制玩具性格和知识。

课程认为玩具需求正在发生以下变化：

- 用户由婴幼儿和儿童扩展至成年人。
- 需求由娱乐、陪伴扩展至教育、安全、社交、解压和情绪价值。
- IP 和技术可能提高产品溢价。
- 线上销售、达人种草、直播、短视频等营销方式的重要性提高。

### 观点

- 玩具行业正在向全年龄段、IP 化、文化化和 AI 智能化演进。
  - 提出人/来源：课程讲师及廖送平听课笔记。
- 技术和 IP 能够提高玩具产品的价格与毛利空间。
  - 提出人/来源：课程讲师。
- 线上销售和内容营销的重要性正在提高。
  - 提出人/来源：课程讲师。

### 推测

- AI 玩具可能形成硬件、模型、内容和角色设定相结合的新产品壁垒。
  - 依据：课程提到通信模组、大模型 API、RAG 和 IP 角色定义。
  - 可信度：中。

- “原材料占成本 60%”。
- “软件授权成本 50%”。
