## 候选主干（贸易公司端）

```text
销售报价（可选）
  → 销售订货（草稿 → 审核中/进行中 …）
    → 转采购（可按供应商拆单；可分批）
      → 待采购 → 开始采购（可进审核）→ 采购中
        → 智能发单（发单状态：待领单 …）
          → 厂商小程序领单 → 采购完成
            ├─ 路径 A：手动结单 → 推进待发货/发货
            └─ 路径 B：生成收货单 → 收货/入库 → 发货/出库
    → 或跳过采购直接发货/排柜（有库存等场景，约束待验证）
→ 客户发货（可生成发货单）
→ 客户应收 / 财务结算（讲解点到入口，细则未展开）
```

## 销售订货（候选）

### 来源与编辑

- 来源：已确认报价单流转，或订货模块直接新建；初态均为**草稿**。
- 仅草稿可编辑主单等相关信息（讲解口径）。

### 多维状态

- **订单状态**候选：草稿、审核中、审核驳回、已撤回、进行中、已结单等（口述对照设计稿）。
- 另有 **采购状态**、**收货/出库（出货）状态** 等独立维度。
- 草稿阶段其他维度可能为空或仅显示草稿（待核对 UI）。
- 转采购后：订单状态可仍为进行中，采购状态变为待采购等。
- 同一客户可多销售订单；同一销售订单可分批转采购。
- 多关联采购单时，采购状态按整体进度回写（AI 摘要称取“最严”状态；精确定义待验证）。

### 结单

- 操作客户发货后可进入已结单；或手动结单。

## 采购（候选）

- 来源：销售转采购，或采购模块手动新增。
- 转采购后可按**供应商自动拆单**。
- 待采购点「开始采购」：若开启审批则进审核；通过后进入采购中。
- **智能发单**：不直接把采购状态改为完成；发单状态更新为待领单，并向厂商发通知（短信/PDF 等）。
- 发单所选厂商**可切换**，不必锁定产品资料预设所属厂商。
- 厂商小程序**确认领单**后：发单状态已领单，采购状态→采购完成，并回写关联销售单采购完成（讲解口径）。
- 采购完结：手动结单，或收货全部完成后自动完结（与部分收货规则联动，见下）。

## 收货（候选）

- 由采购单生成收货单；初态待收货。
- 可选查货模板，控制收货需填字段（含有图/无图等）。
- 支持 PC 与小程序收货；小程序收货人需与登录账号对应。
- 收货箱数可大于/等于/小于采购箱数；大于时可回写采购箱数。
- 部分收货：可多次生成收货单；讲解称仅“完结收货”类操作才向采购单回写收货状态/箱数（细节与后续优化计划待确认）。
- 收货单状态候选：待收货、收货中、收货完成（完成又可分部分/全量子状态，待核对）。
- 收货完成后：可一键入库，或直接对客户发货（与销售侧发货逻辑一致）。
- 入库前提：产品已配置到指定仓库/库位。

## 发货 / 排柜 / 出库（候选）

- 发货入口：销售订货侧客户发货，或收货完成后发货。
- 系统上发货与排柜无强制先后；业务习惯先排后发。
- 手动新增发货单默认待发货；操作发货后变已发货。
- 一键出库：依赖已入库；操作后按钮置灰。
- 发货完成后可生成**客户应收单**进入财务结算。

## 跟单工作台（订单跟踪，候选）

- 面向跟单人员的工作台视角，抓取销售/采购进行中相关数据。
- 页签区分未转采购与已转采购等场景（命名易误解，逻辑待对照设计稿）。
- 操作含更换跟单员、跟单日志、贴纸/客板等进度记录；讲解称部分进度记录不影响上游单据状态。

## 2026-08-28 方案补充（待验证）

来自 [RAW-20260827-004](../../../../04-会议与调研/RAW-20260827-004-8月第1批需求方案-提炼.md)。**方案主张，非正式已上线规格**。飞书图片 alt 有张冠李戴，覆盖范围以正文标题为准。

### 添加产品弹窗表头（#173）

- 可勾选显示字段、全部显示、排序整理、恢复默认、拖拽排序。
- 正文覆盖：销售报价、销售订货、采购订货、物料订货、客户发货、收货。是否含展厅择样、小竹熊内嵌页见 [Q-043](../../../../06-长期记忆/待确认问题.md)。

### 全局列表列宽（#174）

- 系统所有列表记住用户上次拖的列宽。

### 销售明细排序（#178）

- 报价单、销售单产品明细可设排序值。
- 校验：`1 ≤ 值 ≤ 该单明细行数`；数字越小越靠前。
- 改某一行时，区间内其他行同步 ±1（往前排则区间 +1，往后排则 −1）。文中示例：E 从 5 改到 2；B 从 2 改到 6。
- 操作后相关列表/打印导出按用户排序展示。转订货后是否带到销售单见 [Q-044](../../../../06-长期记忆/待确认问题.md)。

### 入库默认箱数（#181）

- 入库箱数默认填未入库箱数。
- 产品绑了多库位时，全部填进第一行库位。

收款红冲见 [展厅摊位与收款红冲](07-展厅摊位与收款红冲.md)。
