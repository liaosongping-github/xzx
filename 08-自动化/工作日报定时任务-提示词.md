# 工作日报定时任务提示词

> 供 Cursor Automations（cron `0 18 * * 1-6`，Asia/Shanghai）使用。与 [协作偏好](../06-长期记忆/协作偏好.md)、[generate-daily-work-report](~/.cursor/skills/generate-daily-work-report/SKILL.md) 保持一致。

## Instructions（粘贴到 Automations 编辑器）

```text
使用 generate-daily-work-report 技能，为本工作空间生成当天中文工作日报草案。

## 上班日判定（必须先做）

1. 读取 06-长期记忆/大小周工作日规则.md，按上海时区判定今天是否为上班日。
2. 非上班日（含周日、小周周六）直接结束，说明跳过原因，不生成日报。

## 生成要求

1. 读取 AGENTS.md、工作台/今日.md、06-长期记忆/协作偏好.md（含「工作日报（对内 / 对外）」）、当天相关的会议/Raw/需求/决策记录。草案优先写入 `00-待确认区/工作日报/`，确认后再落盘正式路径。
2. 同时生成 **对内** 与 **对外** 两份草案；**对外内容必须是对内的子集**。
3. **对外**（提交公司）：
   - 路径：03-产品工作/工作日报/对外/YYYY-MM-DD-工作日报.md
   - 结构：仅「一、今日完成事项」「二、明日工作计划」；单层编号列表
   - 只写业务与岗位相关工作；不得出现 Agent、Raw、自动化、知识库消化落盘等内部细节
   - 样例：03-产品工作/工作日报/对外/2026-08-07-工作日报.md
4. **对内**（工作空间）：
   - 路径：03-产品工作/工作日报/对内/YYYY-MM-DD-工作日报.md
   - 两节下各分「### 对外同步（业务工作）」与「### 仅对内（工作空间 / Agent 协作）」
   - 「对外同步」与对外版逐条语义一致；Agent/Raw/自动化等只写在「仅对内」
   - 样例：03-产品工作/工作日报/对内/2026-08-07-工作日报.md
5. 生成顺序：先提炼对外条目 → 写对外 → 写对内「对外同步」→ 写「仅对内」。
6. 只写有记录支持的内容；不得编造；不得把 Raw 口径升级为已验证事实。

## 确认后落盘（重要）

- **未收到廖送平明确确认前，不要写入本地文件。**
- 在回复中同时给出对内、对外全文，并提示：「请确认；可补充未经 Agent 处理的线下工作。」
- 若廖送平补充线下工作：合并后重新生成两份，再次发送确认；最终确认后再分别落盘。

## 禁止

- 不要写「今日收获」「当前待解决事项」
- 不要保存到 03-产品工作/工作日报/YYYY-MM-DD-工作日报.md（旧单文件路径）
- 不要在未经确认时自动落盘
```

## 触发与调度

| 项 | 值 |
|---|---|
| 名称 | 大小周工作日日报 |
| Cron | `0 18 * * 1-6`（周一—周六 18:00 触发；小周周六在 Instructions 内跳过） |
| 时区 | Asia/Shanghai |

## 维护

协作偏好或双轨日报规则变更时，同步更新本文件，并在 Automations 编辑器中替换 Instructions。
