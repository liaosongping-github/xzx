# 工作周报定时任务提示词

> 供 Cursor Automations（cron `0 18 * * 1-6`，Asia/Shanghai）使用。与 [协作偏好](../06-长期记忆/协作偏好.md)、[generate-weekly-work-report](~/.agents/skills/generate-weekly-work-report/SKILL.md) 保持一致。

## Instructions（粘贴到 Automations 编辑器）

```text
使用 generate-weekly-work-report 技能，为本工作空间生成当周中文工作周报草案。

## 触发日判定（必须先做）

1. 读取 06-长期记忆/大小周工作日规则.md，按上海时区判定今天是否为**当周最后一个上班日**：
   - 大周：仅周六生成
   - 小周：仅周五生成
2. 若今天不是当周最后一个上班日（含周日、小周周六、以及周中各日），直接结束，说明跳过原因，不生成周报。

## 生成要求

1. 读取 AGENTS.md、工作台/今日.md、06-长期记忆/协作偏好.md（含「工作周报」与文风）、当周全部 03-产品工作/工作日报/对外/*.md。草案优先写入 00-待确认区/工作周报/，确认后再落盘正式路径。
2. 仅生成 **1 份**周报，口径同对外日报（业务与岗位相关；不得出现 Agent、Raw、自动化等内部细节）。
3. 结构固定：
   - 标题：`# M月D日—M月D日工作周报（第N周）`（第N周按当周周一所在自然月：floor((日-1)/7)+1）
   - 一、本周完成的工作
   - 二、下周工作计划
   - 三、本周工作总结
4. 正式路径：03-产品工作/工作周报/YYYY-MM-DD至YYYY-MM-DD-工作周报.md
5. 样例：03-产品工作/工作周报/2026-08-03至2026-08-08-工作周报.md
6. 文风直白，禁止「收口」「对齐」「闭环」等套话。
7. 只写有记录支持的内容；不得编造。

## 确认后落盘（重要）

- **未收到廖送平明确确认前，不要写入本地文件。**
- 在回复中给出周报全文，并提示：「请确认；可补充未经 Agent 处理的线下工作与下周计划。」
- 若有补充：合并后重新生成，再次确认；最终确认后再落盘。

## 禁止

- 不要生成对内/对外双份周报（周报仅单份对外口径）
- 不要在未经确认时自动落盘
```

## 触发与调度

| 项 | 值 |
|---|---|
| 名称 | 大小周工作日周报 |
| Cron | `0 18 * * 1-6`（周一—周六 18:00 触发；非当周最后一个上班日在 Instructions 内跳过） |
| 时区 | Asia/Shanghai |
| 实际生成日 | 大周周六 / 小周周五 |

## 维护

协作偏好或周报规则变更时，同步更新本文件与 `~/.agents/skills/generate-weekly-work-report/SKILL.md`，并在 Automations 编辑器中替换 Instructions。
