# Agent 聊天 Raw 自动知识消化任务

处理指定「Agent 聊天」类 Raw 资料，并直接更新当前工作空间。严格遵守根目录 `AGENTS.md`。

## 必须执行

1. 读取指定原始文件。该文件由会话落盘转换而来，默认未验证，不得把助手单方陈述升级为公司事实。
2. 不修改、重排或覆盖 Raw 原始文件。
3. 在 `04-会议与调研/` 新建或更新对应提炼稿，文件名使用 `RAW编号-主题-提炼.md`，至少包含：
   - 资料摘要与适用范围
   - 已验证事实（聊天中通常为“暂无”，除非廖送平明确确认）
   - 观点
   - 推测
   - 未知与待确认问题
   - 决策
   - 行动项（负责人、截止时间、状态）
   - 协作偏好候选 / 工作档案候选
   - 候选业务/产品/系统知识
   - 原始来源相对链接
4. 分类分流写入（按信息分级与安全边界）：

| 落点 | 何时写入 | 状态要求 |
|---|---|---|
| `06-长期记忆/协作偏好.md` | 用户明确偏好，或同一偏好在聊天中多次稳定出现 | 写入“已确认偏好”；临时指令不写；变更记入 `记忆变更日志.md` |
| `06-长期记忆/廖送平-工作档案.md` | 职责、优先级、干系人、工具链等自我陈述或已确认安排 | 区分已确认 / 尚待补充 |
| `06-长期记忆/已验证事实.md` | 仅当用户明确说“这是事实/已验证/可以记为事实” | 极少写入；带来源链接 |
| `02-业务知识库/` | 业务/系统可沉淀内容 | 默认 **待验证**，链接 Raw 与提炼稿 |
| `06-长期记忆/待确认问题.md` | 双方未知或未决，且不与现有 Q 重复 | 分配下一个 Q 编号 |
| `工作台/今日.md` | 明确的当日行动、阻塞、等待反馈 | 增量补充，不清空无关内容 |
| `06-长期记忆/agent切换交接文档.md` | 进行中/刚完成/阻塞/未消化 Raw/建议先读文件有变化 | 增量更新快照与链接 |

5. 更新 `01-原始文件（Raw）/README.md` 对应 RAW 行：
   - **共同允许**：更新「类型、主题、文档摘要、知识库落点」。摘要只写在索引，不写回 Raw。类型可写「Agent 聊天」。
   - **仍禁止修改**：「编号、入 Raw 时间、原始资料」链接列。
   - **执行者差异**：
     - 由流水线/`mode=codex` 自动消化时：不得修改「学习状态、最后学习时间」。
     - 由**当前会话 Agent**消化时：消化完成后必须同时将「学习状态」设为「已学习」，并将「最后学习时间」写为上海时区精确到分钟的时间，格式 `YYYY-MM-DD HH:mm`。流水线随后会据此把队列项同步为已完成。
6. 「知识库落点」列出本次在 `02-业务知识库/` 中形成或更新的条目；若仅更新长期记忆而无业务知识库条目，写「无新增知识（已完成评估）」，并在提炼稿中说明长期记忆落点。
7. 不自动创建正式决策记录；只有聊天明确表明决策已由有权人正式确认时才可更新决策区，并标注来源。
8. 完成前检查新增相对链接可解析；最终回复只需简述处理结果。

## 偏好写入门槛

- 明确表达：如“以后都这样”“请记住”“固定按这个格式”。
- 多次稳定：同一习惯在本条或可追溯的既有偏好中反复出现。
- 不得因单次临时任务指令改写长期偏好。
- 覆盖旧偏好时标注“已失效/被替代”，并写入记忆变更日志。

## 写入边界

- 允许修改：本条提炼稿、`01-原始文件（Raw）/README.md`、`06-长期记忆/` 下的协作偏好、工作档案、待确认问题、已验证事实、记忆变更日志、agent切换交接文档、`工作台/今日.md`，以及与本条直接相关的 `02-业务知识库/` 条目。（拟落库候选宜先进 `00-待确认区/`；强制改写为第二阶段。）
- 禁止修改：任何 Raw 原始文件、`08-自动化/`、`AGENTS.md`、模板、脚本、运行状态、日志或凭据文件。
- 禁止记录密码、令牌、私钥及与工作无关的个人隐私。
- 若发现自动化或权限问题，只在最终回复说明，不得自行绕过。
