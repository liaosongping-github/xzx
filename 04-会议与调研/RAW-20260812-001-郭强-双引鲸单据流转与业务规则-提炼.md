# RAW-20260812-001 郭强：双引鲸单据流转与业务规则提炼

## 资料摘要与适用范围

郭强总发给廖送平理解学习的一张流程图+规则说明图。左侧为报价→销售订单→采购/出货→入库出库与应付应收主链路；右侧为 1–10 条单据规则与底部通用规则。

适用于建立/校准双引鲸贸易端主链路与改单约束的学习假设，并与既有 [单据主链路](../02-业务知识库/系统与流程/双引鲸ERP/模块/05-单据主链路.md)、飞书流程图/状态扭转稿对照。**非正式产品规格书**，全部口径待系统实操与正式资料验证。

## 已验证事实

暂无。

原因：来源为郭强发给学习用的示意图/规则摘要，属 Raw 未验证材料；未与正式字段字典、状态机设计稿或系统实操逐条核对。

## 观点

以下均为图中所写口径（观点/材料主张），权威性待验证。

### A. 流程结构（左侧）

| 主题 | 图中主张 | 证据边界 |
|---|---|---|
| 报价入口 | 销售报价、展厅择样、小竹熊选品报价、站点报价单均可进入销售订单；前三者与「选品转报价」相关 | 流程图节点 |
| 中枢 | 销售订单为一键采购、一键出货计划、一键订单出货的中枢 | 流程图 |
| 采购支路 | 一键采购按厂商分拆 → 按需采购（另有备货采购虚线）→ 采购查货收货 → 一键入库（采购入库）/ 采购应付；查货可「采购收货—一键出货」直连客户出货 | 流程图 |
| 出货支路 | 一键生成出货计划 → 出货/排柜计划 → 订单出货发货 → 客户出货发货；或销售订单一键直接客户出货发货 → 一键出库（订单出库）/ 客户应收 | 流程图 |

### B. 规则要点（右侧 1–10 + 通用）

| 编号 | 图中主张 |
|---|---|
| 1 | 报价→销售订单默认带数；生成后销售订单可手工改，不做数据限制校验 |
| 2 | 报价单无上下游接口限制；已生成客户订单后，报价信息仍可改 |
| 3 | 订单可从报价生成或独立生成；生成时可展示库存仅供参考 |
| 3.1 | 有下游数据后，客户与报价信息不可改 |
| 3.2 | 出货前产品可增删 |
| 3.3 | 订单数量可改；已出货后不得改为小于已出货量；数量=已出货量时提示是否结单 |
| 3.4 | 「厂商信息是否可以修改」——图中表述存疑，待产品确认 |
| 3.5 | 订单已生成应收后，报价公式不可改 |
| 4 | 一键采购按销售订单厂商汇总自动生成；生成后可改；改厂商时提示是否同步；自动数据来自未完结 |
| 4.1 | 手工采购可任意改；收货后厂商锁定；采购数量 ≥ 已收数量 |
| 5 | 查货收货可一键或手工；查未完结采购；收货量 ≤ 采购量；当次收齐时可提示更新采购入库并完结查货状态 |
| 6 | 一键入库默认未入库完结量；入库量 ≤ 查货量 |
| 7 | 应付从查货一键/勾选生成；应付量 ≤ 查货量；生成应付后查货单厂商不可改 |
| 8 | 出货计划从销售订单一键生成，默认本单未完结；可手工加某客户未完结 |
| 9 | 客户出货从销售订单勾选一键生成，默认该客户未完结 |
| 10 | 客户应收从出货一键生成，默认未完结并自动扣减 |
| 通用 | 流转默认带未完结数据，可手工录入；销售转采购可同厂商多销售单合并一张采购单，数量默认可改 |

## 推测

| 推测 | 依据 | 可信度 |
|---|---|---|
| 本图意图对齐/补充廖送平梳理的客户端流程图与状态扭转稿，偏「一键流转 + 未完结数量」产品规则 | 与工作台「流程图第2稿已确认」「状态扭转进行中」同主题；由郭强直接发给学习 | 中高 |
| 「备货采购」虚线表示可独立于按需采购、与销售订单弱耦合 | 图中虚线连到备货采购 | 中 |
| 3.4 可能是产品待决点或画图时自问，非正式已定规则 | 条目写成「是否可以修改」问句形态 | 中 |
| 与 RAW-20260806-001 讲解主链路大体同构，本图更强调一键动作、数量上下限与厂商锁定时点 | 对照既有单据主链路候选页 | 中高 |
