## 观点

以下均为“讲解现场或飞书 AI 章节/摘要所概括的会议口径”，权威性待验证。

| 主题 | 观点或主张 | 证据边界 |
|---|---|---|
| 组织与账号 | 当前端为贸易公司端口；用户挂在组织部门下；部门层级当前无数量上限 | 逐字稿开场确认 + 章节摘要 |
| 角色权限 | 一账号可多角色；权限分 PC/APP；含菜单、功能、数据权限；数据权限为全部/本部门/本人；另有字段级控制 | 讲解演示 |
| 字段权限特例 | 产品信息表字段权限对产品模块下多页面联动生效；其余模块字段权限多为页面/表级一一对应 | 讲解明确区分；需对照权限配置页复核 |
| 业务员/跟单员 | 业务员偏销售侧对接客户；跟单员偏采购侧对接厂商；可同人可不同人；跟单配置停用会同时作用该配置行上的业务员与跟单员，停用后新单不可选；人员下拉取用户管理全量账号 | 讲解口径；停用粒度与账号禁用不同 |
| 编号规则 | 当前不可新增规则，仅可改现有设置；常见为前缀+日期+固定位数流水（讲解称 5 位写死）；也可配客户编号+年月日+当日客户下单数等 | 综合设置演示 |
| 个性化 | 入口在翻译按钮旁；含翻译首字母、体积/材积小数位等全局类配置 | 讲解 |
| 报价公式 | 分公共模板与按账号/角色/客户可见的私有模板；用预设参数（含总费用等）计算产品“报出价”；报出价≠最终销售成交价 | 讲解；与价格字段正式定义仍见 Q-018 |
| 利润率公式 | 关联实时报价；字段旁气泡展示计算逻辑；仅开放出厂价、进货价两项可改，其余项禁改 | 讲解 |
| 审批流 | 生效需「流程启用」+「发起人角色勾选审核相关字段」；发起人未勾选则自动跳过审批；同类型单据仅一条启用流；审批操作从首页待办进入；可配自动通过/条件节点；角色侧审批字段存在冗余、后续拟优化 | 逐字稿长段对齐；与 DYJ-Q-002/Q-024 待办入口相关 |
| 智能发单 | 短信模板池在智能发单模块维护；发单后短信通知并可带 PDF；厂商小程序领单；微信模板逻辑类似但小程序通知能力当时未实现 | 讲解 + 待办验证短信 PDF |
| 公司资料 | 公共信息维护，支撑复制链接选公司并带出信息；与客户资料分处维护的设计有讨论，意向/合作分阶段维护为设想 | 部分细节未澄清后跳过 |
| 参数配置 | 左侧参数项固定，仅可配枚举值；与客户设置逻辑不同；存在关联模块命名不一致，约定后续优化 | 讲解 |
| 销售报价 | 勾选产品后多数字段从产品库带出；报出价由公式计算；整单金额与外箱装量、报价箱数、报价相关；可维护 OEM 子物料；确认后可多次转订货 | 章节摘要 + 讲解 |
| 订货/销售单状态 | 来源：报价流转或直接新建，初态草稿；提交后进入进行中/审核中等；订单含订单状态、采购状态、出库/收货相关状态等多维状态 | 逐字稿复盘段；设计稿曾被打开对照 |
| 采购链路 | 销售转采购可按供应商拆单；待采购→开始采购（可进审核）→采购中→智能发单（发单状态待领单）→小程序领单→采购完成；可选手动结单或生成收货 | 讲解演示 |
| 收货 | 可由采购一键生成；PC/小程序均可收；查货模板控制需填信息；支持部分/全部收货；数量可大于/等于/小于采购箱数；回写规则与“完结收货”相关；讲解称部分逻辑后续可优化（累计已收等） | 章节 + 逐字稿 |
| 发货与结算 | 可不走收货直接推进发货；发货与排柜系统无强制先后，业务习惯先排后发；发货完成后可生成客户应收进入财务结算；销售已结单可由客户发货或手动结单触发 | 讲解 |
| 入库/出库 | 出库依赖已入库；产品需配置到指定仓库/库位才能出库类操作；一键出库后按钮置灰 | 讲解 |
