# 销售报价单列表页高保真原型

- 类型：双引鲸 ERP 全页列表原型
- 对照证据：E-001（销售报价列表）
- 字段来源：[`销售报价单字段字典`](../../../02-业务知识库/系统与流程/双引鲸ERP/字段字典/销售报价单.md)
- 原型入口：[`index.html`](index.html)
- 状态：高保真示意，数据均为演示数据

## 页面范围

本版仅覆盖销售报价列表页，包括状态筛选、条件查询、表格、分页和列设置。新建报价抽屉、报价详情页不在本版范围内。

## 字段处理

- 列设置包含字段字典中全部“列表可显列”字段。
- `唛头名称`仅在新建抽屉可见，因此不作为列表列。
- 默认列按常用浏览场景精简展示，其余字段可在“列设置”中启用。
- `报价公式`为配置型字段，列表内采用摘要文本演示，不推定正式存储格式。

## 交互

- 状态页签、查询、重置、刷新、分页可演示。
- 列设置支持勾选显示字段、全选和恢复默认。
- 批量删除有二次确认；未选数据时给出明确提示。
- 可切换空态、加载态和无权限态，用于检查异常表现。

## 差异与待确认

- 字段字典未记录现网列表筛选项，本原型仅选用已有主表字段构造保守筛选条件。
- 字段字典未记录列表操作全集，本原型只保留已知入口“新增报价”和“详情”，批量删除作为危险操作交互示意。
- 现网状态页签的精确数量与名称待确认；本原型按已确认状态“报价中 / 已转订货”组织。
- 表格列宽、固定列及分页默认条数为原型近似值，正式实现应使用 vxe-table v4。
