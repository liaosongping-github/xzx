# APP产品详情-装柜量

> 产品详情「样品毛/净重」下展示默认 40 尺高柜装柜量；点「查看更多」打开装柜量弹层。  
> V0.2 按廖送平手改稿：蓝链、添加到报价、弹层标题为「装柜量」。数据为演示数据。

关联需求：APP 产品详情页显示装柜量（9 月第 1 批，尚未入池）  
设计规范：跟手改稿；不套 PC 双引鲸壳层  
对照证据：2026-09-09 手改稿（产品详情 + 装柜量弹层）

## 打开方式

用浏览器打开 [`index.html`](index.html)。

## 页面结构

1. **产品详情**
   - 顶栏：× / 产品详情 / 翻译
   - 图集 1/4 + 品名/价格/ENC/编号/货号
   - 产品参数；装柜量在「样品毛/净重」下
   - 默认：`40尺高柜 686箱/8232PCS`；右侧蓝色 `查看更多>`
   - 其他参数；底栏「添加到报价」+ 收起
2. **装柜量弹层**（盖在详情图上，圆角顶）
   - 顶栏：× / 装柜量 / 翻译
   - 产品信息：产品编号、外箱装量、外箱长度、体积/材积
   - 以体积(CBM)为准：20 / 40 / 40高 / 45高
   - 以材积(CUFT)为准：同上
   - 箱数/PCS 为蓝字
   - 底栏同样「添加到报价」+ 收起；× 或 ∨ 关闭

## 演示数据

详情产品跟手改稿：沙滩车6pcs… / `YP52621510` / 外箱 `63*30*63` / `2/72`。

弹层 40尺高柜与详情默认一致：`686箱/8232PCS`。其余柜型为示意分档，不是手改稿里的重复占位数字。

## 可点示意

- 装柜量行 / 「查看更多」→ 弹层
- 弹层 ×、遮罩、右下 ∨ → 回详情
- 右侧可切「有装柜量 / 无体积」
