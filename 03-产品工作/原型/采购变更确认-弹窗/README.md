# 采购变更确认弹窗

## 弹窗结构（跟手改稿）

一条待确认组 = **一张销售订货单**，内含本次有变更的采购订货单。卡片结构：

1. **销售卡外框**：灰边白底；**销售头灰底** `#f5f7fa`（销售订货单 + 客户名称 + 修改产品数；头加高）
2. **采购卡（内嵌、白底、灰边圆角）**：采购订货单 + 厂商名称 + 修改人 + 修改时间 +（待确认）**整单拒绝 / 整单同意**
3. **产品块**：产品头灰底；缩略图 + 品名 + 产品编码 + 客户货号 +（待确认）**拒绝更新 / 同意更新**；（已处理已同意）**操作人：姓名 + 时间 + 已同意（绿字）** / **已拒绝**
4. **对照表 5 列**：序号、字段名、采购单当前值、销售单当前值、同意后销售单值更新为  
   - 末列含表头浅蓝底；已拒绝则末列划线；已同意则划「销售单当前值」  
   - 序号居中；无斑马纹/行 hover  
   - 卡片标签用单据全称、全角冒号；表头短称按稿  
   - 「同意后」可以等于销售当前值、不等于采购当前值（如采购折扣）

页签：`待确认 (N)` 为**销售单组数**；**已处理不带条数**。无图例。无底栏按钮，关窗靠右上 ×。底部分页铺开（示意：左「共 50 条 + 100」/ 中 1–5 页 / 右「前往」）。提示条通栏浅蓝底，上下与标题栏、页签各间隔 20px（弹窗内容区 padding）。采购卡之间、销售头与采购卡之间留空隙。

已处理筛选：标签「单号查询」，占位「采购单号/销售单号」；处理结果默认「全部」。

## 演示数据

待确认 2 组销售单：`SO001`（3 个产品：PO001 遥控赛车/充电套装 + PO002 泡泡枪）/ `SO002`（PO003 积木套装）。

已处理：`SO001` 3 个产品已同意（操作人：李销售，2026-08-28 14:22）；`SO002` 已拒绝（不显示操作人/时间）。

字段示意：产品名称、采购折扣、外箱装量、内盒个数。

## 可点示意

- 操作栏「采购变更确认(n)」打开弹窗
- 待确认 / 已处理 页签
- 整单同意/拒绝、产品同意更新/拒绝更新（二次确认）
- 已处理：单号查询 + 处理结果 + 底部分页示意
- 列表：产品查询抽屉、列设置抽屉（组件库）
- 演示工具可切：有待办 / 空态 / 无权限
