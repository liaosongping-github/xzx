## 主路径与可点示意

- 侧栏「客户账号 / 厂商账号」切换列表。
- 点「客户编号 / 厂商编号」新开页签进入账号详情。
- 详情 Tab：客户为「消费明细 / 应收明细 / 销售明细」；厂商为「消费明细 / 应付明细 / 采购明细」。
- 列表查询、详情「收起」账号信息可点；工具图标为静态示意。
