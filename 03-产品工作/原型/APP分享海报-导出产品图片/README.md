## 设计结论（本版按此画）

把现网 3 个导图入口收成 **一个功能：导出产品图片**。差别只是图上带不带参数：

| 导出类型 | 对应现网 | 图上带什么 |
|---|---|---|
| 原图 | 批量导出图片 | 不带参数 |
| 水印图 | 批量导出水印图 | 表格水印 / 纯文字水印 |
| 分享海报 | 分享海报（现仅单品） | 模板 + 价格加点 + 厂商信息 |

- **PC 列表**：`更多操作` 下不再拆「批量导出水印图 / 批量导出图片 / 分享海报」，只留 **导出产品图片**。
- **PC 详情**：底栏「分享海报」改名为 **导出产品图片**，打开同一弹窗（默认落到「分享海报」）。
- **APP**：产品详情底栏增加 **导出图片**；列表可多选后导出。三种类型与 PC 同一套设置。

## 现网对照（2026-09-10 贸易端实测，廖送平02）

1. **批量导出水印图**：宽弹窗约 1400×709。水印模式「表格 / 纯文字」。表格：颜色、13 个内容芯片、为零是否显示、图片命名、中/英、按厂商分组。纯文字：对齐、边距、字号/粗细/颜色、15 个芯片 + 模板文本框（无显示语言）。底栏：取消 / 保存设置 / 预览水印 / 确认导出。
2. **批量导出图片**：约 614×406。提示「相同产品编号只导出一款」。图片命名（产品编号默认）、图片范围（首图默认）、分组（按产品编号独立文件夹默认勾，按厂家默认不勾）。关闭 / 确定。
3. **分享海报**：详情底栏进入，约 1100×700。左选模板、中预览、右内容设置（语言、6 项分享内容默认全勾、出厂价、加点/减点、货币、汇率、显示价格、复制图片）。列表「更多操作 → 批量导出」子菜单当前只有水印图/图片，**没有**分享海报（截图里的第三项来自详情或另一账号，本原型按需求把海报并进统一入口）。

详情底栏仍保留「下载所有图 / 复制参数」等，本期不改。

## 主路径与可点示意

**PC**

- 勾选产品 → `更多操作` → `导出产品图片` → 切 原图 / 水印图 / 分享海报。
- 未勾选会 toast「请先勾选产品」。
- 点产品编号打开详情 → 底栏「导出产品图片」。
- 水印图可切表格/纯文字；芯片可点选；海报可切模板、勾分享内容、改加点后显示价格会变。
- `保存设置 / 预览 / 确认导出 / 复制图片` 为示意 toast，不真下载体。

**APP**

- 产品列表：勾选 → 底栏「导出图片」。
- 产品详情：底栏「导出图片」（默认海报）。
- 导出页：顶部分段 原图 / 水印 / 海报；底栏「保存图片」。
