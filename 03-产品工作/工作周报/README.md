# 工作周报

与 [工作日报](../工作日报/README.md) 同级，按周归档。口径为**单份对外逻辑**（业务与岗位相关）。

## 结构

1. 一、本周完成的工作  
2. 二、下周工作计划  
3. 三、本周工作总结  

标题格式：`# M月D日—M月D日工作周报（第N周）`。  
文件名：`YYYY-MM-DD至YYYY-MM-DD-工作周报.md`（起止为当周上班日起止日）。

## 生成

- Skill：`generate-weekly-work-report`（权威源 `~/.agents/skills/generate-weekly-work-report/`）
- 模板：[工作周报-模板](../../07-模板/工作周报-模板.md)
- 定时提示词：[工作周报定时任务-提示词](../../08-自动化/工作周报定时任务-提示词.md)（大周周六 / 小周周五 18:00）
- 规则见 [协作偏好](../../06-长期记忆/协作偏好.md)
