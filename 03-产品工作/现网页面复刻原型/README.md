# 双引鲸贸易端 · 现网页面复刻原型

把贸易端现网 `https://trade.tsbsoft.com` 复刻为**可本地打开、可操作**的高保真静态原型。纯 HTML/CSS/JS，无框架、无 CDN、无构建步骤。

> 阶段：**阶段1 已完成，等待确认后再进入阶段2**（阶段2 才铺开其余菜单页）。

## 怎么打开

双击根目录 `index.html`（自动跳 `页面/首页/index.html`），或直接打开任一页面文件。相对路径引用，`file://` 协议即可运行，无需起服务。

- 推荐分辨率 ≥ 1400 宽（现网最小宽度 1400）。
- 多页签状态用 sessionStorage 保持；关掉标签页即清空，不写任何后端。

## 可点路径（自检主线）

侧栏折叠/展开 → 菜单查询过滤 → 首页工作台「产品资料」→ 状态页签切换（条数变化）→ 关键字查询（如「遥控」）→ 综合查询抽屉填条件确定（表格变化、重置还原）→ 新建产品（锚点定位、必填校验）→ 行编辑 → 列设置开关字段 → 行删除（二次确认后本地移除）→ 导入产品 → 页签切换/关闭 → 任意未建菜单进占位页。

## 数据说明

- 演示数据在 `数据/产品资料.js`，以全局 `window.DYJ_PRODUCTS`（24 条虚构产品）+ 页签计数提供，**全部为明显虚构数据，无真实客户/产品/图片**。
- **为什么不用 `.json` + fetch**：`file://` 下浏览器以 CORS 拦截本地 JSON 读取，双击打开会失败；改用 `.js` 全局变量是静态原型的常规做法，阶段2 若起本地服务可换回 JSON。
- 产品图片列一律灰底文字占位，未下载任何真实产品图；logo 为现网公开 logo 资源。
