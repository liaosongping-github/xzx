## 背景与目标

提供一页低保真需求详情示例，验证 PRD 与原型的关联方式。

## 用户和场景

廖送平在首次使用工作空间时，通过示例理解真实 PRD 应如何编写。

## 业务流程

`打开需求 → 阅读 PRD → 查看原型 → 返回需求`

## 功能范围

- 展示需求名称、状态和目标。
- 展示主要操作按钮。
- 提供返回需求文档的入口。

## 页面与交互

- 页面顶部显示“演示数据”提示。
- 点击状态按钮仅在页面内切换演示状态，不保存数据。
- 点击“需求文档”可打开关联 Markdown 文件。

## 业务规则

- 演示状态不得同步到真实需求池。
- 页面不请求网络、不采集数据。

## 异常场景

- 浏览器若无法直接打开 Markdown 链接，可在文件管理器或编辑器中打开对应文件。

无。MVP 示例不包含埋点。
