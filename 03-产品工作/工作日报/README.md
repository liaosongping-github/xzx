# 工作日报

按工作日归档，分为 **对内** 与 **对外** 两份；规则见 [协作偏好](../../06-长期记忆/协作偏好.md)「工作日报（对内 / 对外）」。

| 目录 | 用途 | 结构 |
|---|---|---|
| [对外/](对外/) | 提交公司 | 单层编号列表 |
| [对内/](对内/) | 工作空间全量记录 | 「对外同步」+「仅对内」两节 |

文件名均为 `YYYY-MM-DD-工作日报.md`。

## 生成顺序（Agent / 自动化）

1. 从工作台、会议、线下补充等提炼 **对外条目**（业务口径）。
2. 写 **对外** 正文（单层列表）。
3. 写 **对内**：「对外同步」与对外逐条一致 → 再写「仅对内」。
4. 发廖送平确认（可补充线下工作）→ 有补充则重生成两份 → 确认后落盘。
