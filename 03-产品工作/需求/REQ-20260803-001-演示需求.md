# REQ-20260803-001 演示需求

> **演示数据：** 本文只展示文档结构和关联方式，不代表公司真实业务，也不得进入已验证事实。

## 背景与来源

为验证工作空间中的需求、PRD、决策与 HTML 原型能否互相追溯，创建一个演示需求。

## 当前问题

新工作空间尚无完整样例，使用者可能不清楚如何组织一项需求的相关产物。

## 目标用户与场景

- 用户：廖送平。
- 场景：首次创建真实需求前，参考一套端到端文档结构。

## 目标与非目标

**目标**

- 展示需求文档的最小结构。
- 展示需求、PRD、决策和原型之间的双向链接。

**非目标**

- 不代表真实业务需求。
- 不用于研发排期或验收。

## 需求范围

- 提供一个演示 PRD。
- 提供一个可直接打开的演示 HTML 原型。
- 提供一条演示决策记录。

## 优先级

演示用途，不参与真实优先级排序。
