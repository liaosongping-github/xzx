# 双引鲸设计与交互规范

> 本文是总则和索引。做页面时优先读取 [组件库](组件/README.md)、对应的 [页面模式](页面模式/) 与 [证据与待确认](证据与待确认.md)，避免把单页观察扩大为全局规则。

## 1. 适用范围与保真度

- 适用于贸易端（`trade`）双引鲸相关 **HTML 高保真原型** 与需求示意页。
- 正式前端实现以 **Element Plus** + **vxe-table v4** 为准；本规范提炼可复用的壳层与交互约定，不替代组件库文档。
- 信息分级：页面观察、可信度与未知项统一记录在 [证据与待确认](证据与待确认.md)；与现网冲突时以现网为准并回写证据台账和对应页面模式。

## 2. 权威优先级

1. **现网实装**：色板与壳层尺寸以 [S-001](证据与待确认.md#s-001前端全局样式代码)（前端 `style/`）为准；页面结构以截图 E-001～E-004 为准（先登记至证据台账）
2. **本目录规范与 tokens**（从现网提炼的可复用约定）
3. **摹客设计稿**（结构、密度、抽屉/更多菜单等）；冲突默认跟现网，差异写入「待确认」

## 3. 整体布局（App Shell）

| 区域 | 约定 |
|---|---|
| 左侧侧栏 | 深色底 `#333744`，宽 `210px`（收起 `54px`）；顶为 Logo「双引鲸」；菜单图标+文案；展开分组带 chevron |
| 激活菜单 | 主色实心底 + 白字 |
| 顶栏 | 白底；左「菜单查询」；右：时间、天气、消息角标、设置、语言、头像与账号 |
| 多页签 | 顶栏下横向页签；**激活页签主色实心底**；可关闭 |
| 内容区 | 页面灰底 `#f0f2f5`；内容白卡片/白面板 + 轻阴影 |

模板：`templates/列表页壳层.html`、`templates/详情页壳层.html`。

## 4. 视觉 Token

- 变量文件：[`tokens.css`](tokens.css)；组件级尺寸见 [组件/视觉规范](组件/视觉规范.md)
- 主色：`#009DFF`（vxe / 侧栏激活条；非 Element Plus 默认蓝）
- 成功/导入绿：`#00B56A`
- 警告/进行中橙：`#FF7C00`
- 危险红：`#FF6624`
- 审核中紫（表内文字色，截图观察）：约 `#9B59B6`（style 未出现）
- 字体：微软雅黑；正文 13–14px；表格可到 12px（高密度）
- 控件高：约 32px；表头约 28px、表体行约 32px；圆角约 4px
- 页面最小宽：`1400px`；常规弹窗最小 `500px`，宽版 `1000px`；内容区 padding `20px`（`--dyj-dialog-body-padding`，不是查询行间距 15px）
- **禁止**套用通用「AI 落地页」风格（大圆角卡片墙、紫渐变、Inter 默认站等）

### 5.1 列表页（产品资料 / 销售订货 / 采购订货）

自上而下：

1. **状态/分类页签**（文案页签 + 底部主色下划线；如「进行中」「草稿」）
2. **筛选区**：输入框、下拉、日期范围；主按钮「查询」；次按钮「重置 / 综合查询 / 产品查询」
3. **工具栏**：
   - 左：主操作（`+ 新增…` 主色）、成功色「导入」、描边次操作、「批量删除」等
   - 右：表格工具图标簇（全屏、刷新、列设置、导出、打印）
4. **数据表**（按 vxe-table 观感）：表头灰底、可选斑马纹、勾选列、序号、缩略图、**编号蓝色链接**、右侧操作列
5. **分页**：右下；总数 + 每页条数 + 页码 + 跳转

### 5.2 详情页（订货明细等）

1. 可折叠 **信息区**（订货信息：label-value 多列描述列表）
2. **报价公式**等业务块（标题 + 右侧主色按钮 + 简单表）
3. **明细工具栏**（多色按钮区分动作：添加产品 / 转采购 / 排柜 / 资产发货等）
4. **明细表**（多状态列；操作链「换供应商 / 唛头 / 装箱 / 更多」）
5. 底部 **汇总条**（数量、重量、体积、金额；关键合计可强调色）

### 5.3 弹窗表单（编辑采购订单等）

- 居中 Modal；标题左、关闭右
- 内容区 padding `20px`（`--dyj-dialog-body-padding` / `--dyj-space-xl`）；不要用 `--dyj-filter-gap`（15px，仅查询条件行间距）
- 表单常见 **两列栅格**；必填红 `*`
- 页脚右对齐：`关闭`（次）+ `确定`（主色）
- 遮罩约 45% 黑

### 5.4 抽屉（摹客常见「查看信息」）

- 右侧滑出约 400px；用于查看/轻编辑
- 与现网并存时：列表「更多」可出菜单；查看类可用抽屉或新页签——**默认跟目标页现网**；无现网则优先抽屉（摹客）

### 5.5 首页工作台

- 多卡片：快捷入口宫格、图表、待办列表、排行表
- 待办：红色圆点 + 文案 + 时间；「查看全部」右链

## 6. 组件映射（实现时）

| UI | 建议组件 |
|---|---|
| 布局壳 | `el-container` / 自研壳 + 本 `shell.css` |
| 按钮/输入/分页/弹窗/抽屉/日期 | Element Plus |
| 复杂表格、列设置、固定列、合计行 | vxe-table / `vxe-grid` |
| 图表 | 现网同类（ECharts 常见） |
| 状态 | 表内彩色文字或 `el-tag`；**先对照目标页现网**，勿混用两套 |

## 7. 交互约定（默认；可被现网覆盖）

| 场景 | 默认 |
|---|---|
| 行内主操作 | 文字链：编辑（蓝）、删除（橙/警告色）、更多 |
| 更多 | 下拉/弹出菜单（改状态、审核、打印等） |
| 单据编号 / 产品货号 | 蓝色链接，进入详情或新页签 |
| 删除 / 批量删除 | 二次确认（Element MessageBox 风格） |
| 查询 | 点「查询」触发；重置清空条件 |
| 新增 | 主色按钮，带 `+` |
| 导入类 | 成功绿按钮 |
| 页签 | 多开；关闭不丢侧栏上下文 |
| 空态 | 表区居中简短说明 + 主操作入口 |
| 加载 | 表区 loading 遮罩 |
| 校验失败 | 字段下红字 / 顶部错误提示，不静默 |

## 8. 按钮色语义（观察值）

| 色 | 典型动作 |
|---|---|
| 主色蓝 | 查询、新增、确定、设置公式 |
| 绿 | 导入、转采购、排柜计划 |
| 橙 | 资产发货、部分强调业务动作、删除链 |
| 白底描边 | 批量操作、次要操作 |

## 9. 摹客 vs 现网

- 摹客可出现：更密筛选、右侧抽屉、不同首页图表、操作菜单项更多。
- **视觉与控件形态跟现网**；摹客用于补交互 completeness。
- 菜单树以知识库 [07-菜单树](../../../02-业务知识库/系统与流程/双引鲸ERP/07-菜单树.md) / 现网为准，不以旧摹客信息架构覆盖。

## 10. Agent 产出要求

1. 做双引鲸原型前读取本规范 + `tokens.css` + [组件库](组件/README.md)。
2. 全页复制组件片段（全局壳 / 查询 / 列表 / 列设置 / 产品选择器），只改插槽，禁止重画侧栏和主色。
3. 新原型放 `03-产品工作/原型/<需求编号>-名称/`，引用 `shell.css` 与 `components.css`。
4. 交付时附 [交付检查清单](交付检查清单.md)；有意偏离须写明原因。
5. 演示类非双引鲸需求（如 REQ-20260803-001）可不套本规范。
