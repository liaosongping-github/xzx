# 双引鲸原型交付检查清单

交付前逐项勾选；有意偏离须在原型 README 写明。

## 范围与证据

- [ ] 全页已引用 [组件/全局壳](组件/README.md)，未重画侧栏/顶栏/页签
- [ ] 列表已引用查询条件与列表/列设置片段；选品已引用产品选择器或产品查询抽屉
- [ ] 已判断原型是全页、列表、详情、弹窗或首页；已读取对应页面模式
- [ ] 原型 README 已写明对照证据编号（`E-001`～`E-005` / `S-001`）或“无现网证据，待确认”
- [ ] 页面字段、状态、操作来自需求或目标页面；未把模板演示项当成业务事实

## 壳层

- [ ] 左侧深色侧栏 + Logo「双引鲸」
- [ ] 顶栏工具区（时间/消息/用户可简化，但位置正确）
- [ ] 多页签；激活态主色实心底
- [ ] 内容区灰底 + 白面板

## 视觉

- [ ] 引用 `tokens.css` / `shell.css` / `components.css`，未另起紫渐变/大圆角营销风；未在 HTML 写死 px/色值
- [ ] 主色按钮与链接为 `#009DFF`（引用 `tokens.css`，勿用 Element Plus 默认 `#409EFF`）
- [ ] 导入类用绿、删除/警告用橙或红，语义不混

## 列表页

- [ ] 有状态/分类页签（若业务需要）
- [ ] 筛选 + 查询/重置
- [ ] 工具栏左操作、右表格图标簇（可简化数量）
- [ ] 表头灰底；编号为蓝色链接；操作列为文字链
- [ ] 底部分页区

## 详情 / 弹窗 / 抽屉

- [ ] 详情分区清晰（信息 / 公式或业务块 / 明细表）
- [ ] 弹窗两列表单 + 必填 `*` + 底栏关闭/确定
- [ ] 抽屉仅在现网或摹客已有该模式时使用

## 交互与异常

- [ ] 演示数据、高保真示意已明确标注
- [ ] 关键操作可点击演示，或已明确标注为静态示意
- [ ] 适用时已覆盖空态、加载、校验/提交失败、无权限和危险操作二次确认
- [ ] 与现网存在差异时，README 已写明差异、原因和待确认项

## 说明

- [ ] 原型内标注「高保真示意 / 演示数据」
- [ ] 对照页（现网或摹客）已在 README 写明
- [ ] 与现网/摹客差异已列出（有则必写）
