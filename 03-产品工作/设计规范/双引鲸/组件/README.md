# 双引鲸原型组件

> 高保真原型**引用本目录片段**，不要按印象重画壳层和表格。本库服务 Agent HTML 原型，不替代现网 Element Plus / vxe-table。

## 怎么用

1. 全页原型：复制 [全局壳](snippets/全局壳.html)（侧栏+顶栏+页签），只改当前菜单高亮和页签文案；页面引入 `shell.css` + [`shell.js`](../shell.js)（一级点击展开二级）。
2. 列表页内容区：按需插入 [查询条件](snippets/查询条件.html) + [列表](snippets/列表.html)；列设置用 [列设置抽屉](snippets/列设置抽屉.html)。
3. 选品/加产品：引用 [产品选择器](snippets/产品选择器.html)；列表上的「产品查询」用 [产品查询抽屉](snippets/产品查询抽屉.html)。
4. 对照视觉：[组件画廊](../templates/组件画廊.html)。尺寸/色/字号见 [视觉规范](视觉规范.md)，变量在 [`tokens.css`](../tokens.css)。
5. 样式：`shell.css` + `components.css`，禁止另写一套主色/侧栏，禁止在 HTML 写死 px 或色值。

## 分层

| 层 | 组件 | 全局？ | 个性（插槽） |
|---|---|---|---|
| 全局壳 | [菜单](菜单.md)（含顶栏、页签） | 是，每个全页都挂 | 当前模块展开、叶子高亮、页签标题 |
| 页面骨架 | 列表页 = 状态页签 + 查询 + 工具栏 + 表 + 分页 | 否 | 页签文案、按钮、列、操作 |
| 业务组件 | [查询条件](查询条件.md)、[列表与列设置](列表与列设置.md)、[产品选择器](产品选择器.md) | 否 | 字段来自本页/字段字典 |

局部嵌入（只要弹窗、不要侧栏）时，不强制挂全局壳。
