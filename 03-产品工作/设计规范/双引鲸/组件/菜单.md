# 菜单（全局壳）

**全局。** 每个全页原型都挂；局部弹窗原型不强制。

## 共性（不要改）

- 左侧深色侧栏 `#333744`，宽 `210px`；顶为 Logo「双引鲸」
- 一级菜单：图标 + 文案 + 右侧 chevron；激活项主色实心底 + 白字
- **点击一级展开/收起二级**（可同时展开多个分组）；箭头 `▸` / `▾`
- 展开分组后叶子缩进；当前叶子高亮
- 顶栏：折叠钮（可示意）+「菜单查询」；右侧消息/设置/语言/头像可简化
- 顶栏下多页签；**激活页签主色实心底**

树数据以 [菜单树](../../../02-业务知识库/系统与流程/双引鲸ERP/07-菜单树.md) 为准，原型可只展开当前模块。

## 个性（插槽）

- `data-active-group`：当前一级（如销售管理）
- `data-active-leaf`：当前叶子（如销售报价）
- 页签标题与可否关闭

## 引用

复制 [`snippets/全局壳.html`](snippets/全局壳.html)，改高亮与页签，不要重画侧栏配色。全页须同时引入 `shell.css` 与 [`shell.js`](../shell.js)。二级菜单数据见 [菜单树](../../../02-业务知识库/系统与流程/双引鲸ERP/07-菜单树.md)。
