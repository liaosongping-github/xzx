# 查询条件

**非全局。** 布局和按钮固定，字段按页面换。

## 共性

- 一行横排，控件高 32px，间距约 15px
- 主按钮「查询」（主色）；旁路「产品查询」或「综合查询 / 图搜」（白底描边）
- 点「查询」才触发；不要做成输入即搜
- 关键词框可带右侧综合查询图标（现网 `icon-synthesize`）

## 个性

| 页面 | 现网观察（2026-08-31） |
|---|---|
| 销售报价 | 关键词 + 订单状态下拉（报价中/已转订货/全部报价单）+ 时间范围 + 查询 + 产品查询 |
| 销售订货 | 时间范围 + 订单状态（默认可为「全部」）+ 查询 + 产品查询；另有状态页签（草稿订单/进行中/…） |
| 产品资料 | 是否有图 / 是否停产 / 产品状态 + 查询 + 综合查询 + 图搜 |

字段必须来自目标页或字段字典，禁止把报价筛选项抄到别的列表。

## 两种「产品查询」

1. **列表按钮「产品查询」**：右侧抽屉，按产品属性筛单据/资料，见 [产品查询抽屉](snippets/产品查询抽屉.html)。
2. **单据「+ 添加产品」**：居中弹窗选品写入明细，见 [产品选择器](产品选择器.md)。不要混用。
