# 组件视觉规范

> 尺寸、颜色、字号的唯一出处是 [`tokens.css`](../tokens.css)。HTML 片段只写 class，禁止 `style="width/color/font-size"`。

## 通用

| 项 | Token | 值 |
|---|---|---|
| 字体 | `--dyj-font-family` | 微软雅黑 |
| 正文 | `--dyj-font-size-sm` / `base` | 13px / 14px |
| 表格 | `--dyj-font-size-xs` | 12px |
| 主色 | `--dyj-color-primary` | `#009DFF` |
| 文字 | `--dyj-text-primary` | `#333` |
| 控件高 | `--dyj-control-height` | 32px |
| 表头/表体行高 | `--dyj-table-header-height` / `--dyj-table-row-height` | 28px / 32px |
| 圆角 | `--dyj-radius` | 4px |
| 弹窗内容区 | `--dyj-dialog-body-padding` | 20px（与 `--dyj-space-xl` 同值） |

## 弹窗（通用）

| 项 | Token | 值 |
|---|---|---|
| 常规最小宽 | `--dyj-dialog-min-width` | 500px |
| 宽版 | `--dyj-dialog-wide-min-width` | 1000px |
| 内容区 padding | `--dyj-dialog-body-padding` | 20px；`.dyj-modal-body` |
| 遮罩 | `--dyj-mask` | 45% 黑 |

来源：原型壳层 `shell.css`。**不要**把 `--dyj-filter-gap`（15px，查询条件行间距）用到弹窗内容区。现网 EP Dialog 内边距待对照。

## 禁止

- 在原型 HTML 写死 `px`、`#hex`、Element 默认蓝 `#409EFF`
- 把列设置做成居中大弹窗，或把添加产品做成右侧抽屉
