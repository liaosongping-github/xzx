# 产品选择器

**非全局。** 入口和回填字段按单据变。

## 变体

| 变体 | 入口 | 现网 |
|---|---|---|
| A. 列表产品查询 | 列表「产品查询」 | 右侧抽屉，分组筛产品属性，底栏重置/确定。**只改查询条件，不把产品写入明细。** |
| B. 单据添加产品 | 详情工具栏「+ 添加产品」 | 主色按钮。草稿等可编辑态可开；进行中常 **disabled**。 |

## 变体 B 共性（2026-08-31 草稿订货对照）

- **居中 Modal**（`el-dialog ts-dialog`），约 **916×744**，可拖动；**不是**右侧抽屉
- 标题「添加产品」，右上角 × 关闭；**没有**底栏关闭/确定
- 页签：单个产品（默认）/ 组合资料 / 客户产品 / 客户专属
- 查询：关键词「请输入」+「出厂价：」最低 — 最高 + 主色「查询」
- 旁路：「按编号列表查询」「按出厂货号查询」（描边）
- 主操作在查询行右侧：「批量提交选中产品（N）」，N 为勾选数
- 表：勾选 + 序号 + 产品图片 / 产品编号 / 产品名称 / 出厂货号 / 客户货号 / 出厂价 / 进货价 / 标贴费 / 起订量 / 分类编号
- 底部分页：共 N 条记录 + 每页条数 + 页码（现网可见 100 条/页）
- 原型点「批量提交」只做示意，**不要对现网点提交**

## 个性

- 页签是否全有、筛选项、表列 → 目标单据
- 提交后回填哪些明细列 → 该单据字段字典
