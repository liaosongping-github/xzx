# 列表与列设置

**非全局。** 表格交互固定，列和操作按页面换。

## 列表共性

- 上：状态/分类页签（有则用，文案页签 + 底部主色下划线）
- 中：工具栏左主操作（`+ 新增…` 主色）、次操作描边；右圆形图标簇
- 表：灰表头、可选斑马纹、勾选列、序号、**编号蓝色链接**、右侧文字操作（生成链接/详情/更多 等）
- 表头可示意升序/降序（vxe 小三角）
- 底：总数 + 每页条数 + 页码；现网报价列表可见「100条/页」

右侧图标簇（单据列表现网顺序）：全屏、展开、刷新、下载、打印、**字段管理**。产品资料在展开后多一个宫格。

行内操作现网：主色文字「生成链接」、绿色文字「详情」、默认「更多」。

## 列设置共性（字段管理）

现网为**右侧抽屉**（产品资料列设置实测 710px，E-006；销售报价约 514px，按页面实测取值），不是居中大弹窗。产品资料为四列蓝色 chip（已显示蓝底/未显示灰底，带眼睛与拖拽柄），全集 61 字段。

- 标题：勾选您要显示的字段
- 工具：设置全部显示 / 排序整理 / 恢复系统默认
- 查询框 + 主色「查询」
- 字段勾选列表
- 底栏：关闭 + 保存

## 个性

- 列名、默认显示列、固定列 → 字段字典「列表可显」
- 左工具栏按钮 → 目标页现网
- 状态页签 → 仅目标页存在时加
