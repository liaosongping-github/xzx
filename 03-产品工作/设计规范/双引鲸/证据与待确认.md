# 双引鲸原型规范证据与待确认

> 本文只记录页面观察，不把截图推断升级为业务事实或研发实现要求。原型需优先引用适用证据；新截图进入本台账后再影响规范。

## 使用方式

- 原型 README 写明对照证据编号，例如：`对照：E-001（销售报价列表）`。
- 页面模式文件只提取跨页面可复用的呈现规则；单页业务字段、状态流转仍以目标页面与业务资料为准。
- “待确认”意味着可采用保守展示，但不得当作全系统统一规则。

## E-001｜销售报价列表

- **来源**：2026-08-12 现网截图（销售报价页）。
- **观察**：深色左侧导航、白色顶栏和横向多页签；内容区浅灰；筛选区、操作工具栏、密集数据表、右侧固定操作列、底部分页同时出现。激活侧栏和激活页签均为亮蓝色实底；报价中为橙色文字。
- **可复用规则**：全页列表原型使用 App Shell；表格以高密度、浅灰表头、蓝色编号链接和文字操作为优先呈现；分页位于表格下方。
- **可信度**：高（现网单页直接观察）。
- **待确认**：所有列表是否都有状态筛选页签、所有操作列是否固定。侧栏宽度见 S-001（代码 `210px` / 收起 `54px`）。

## E-002｜销售报价详情

- **来源**：2026-08-12 现网截图（报价明细页）。
- **观察**：详情在同一 App Shell 与页签中打开；上部为可收起的信息区；报价公式以单独白色块呈现；明细表上方有业务操作、筛选与表格工具；底部有横向汇总条。转为订货使用绿色按钮，主要查询与设置操作使用蓝色。
- **可复用规则**：单据详情可按“信息区 → 业务块 → 明细表 → 汇总”组织；汇总只在目标业务确有合计时使用。
- **可信度**：高（现网单页直接观察）。
- **待确认**：信息区是否均可折叠、所有详情是否都有底部汇总、按钮色与业务动作的全局映射。

## E-003｜编辑产品资料弹窗

- **来源**：2026-08-12 现网截图（编辑产品资料）。
- **观察**：宽幅居中 Modal，左侧为分组锚点导航，右侧为多列高密度表单；必填项使用红色星号；文件上传以虚线方框和加号表达；底部固定“关闭 / 确定”。
- **可复用规则**：复杂资料维护可使用“左侧分组 + 右侧分区表单”的弹窗；短表单不强制复制该结构。
- **可信度**：高（现网单页直接观察）。
- **待确认**：表单栅格数、上传控件在其他模块的统一形态。常规弹窗最小宽见 S-001（`500px` / 宽版 `1000px`）。内容区 padding 原型按 `20px`（`--dyj-dialog-body-padding`）；现网 Element Plus Dialog 是否同值待对照。

## E-004｜首页工作台

- **来源**：2026-08-12 现网截图（首页）。
- **观察**：首页仍使用同一 App Shell；工作台采用多个白色业务面板，包含快捷入口、订单统计图、待办列表和排行榜表格；面板标题区带时间范围或查看全部入口。
- **可复用规则**：首页优先采用业务信息面板与高密度表格，不使用营销式大卡片、渐变横幅或装饰性插画。
- **可信度**：高（现网单页直接观察）。
- **待确认**：图表类型、快捷入口数量和排名色彩是否可复用到其他工作台。

## E-005｜贸易端组件实装（2026-08-31）

- **来源**：登录后浏览器只读对照 `https://trade.tsbsoft.com`（首页、销售报价、销售订货详情、产品资料、草稿订货「添加产品」弹窗）。
- **观察**：
  - 全局壳：侧栏 `el-menu` 宽 210px、底 `#333744`；激活项主色实心底；顶栏「菜单查询」；页签激活主色实心底。
  - 查询：销售报价为关键词 + 订单状态 + 时间范围 +「查询」「产品查询」；「产品查询」为右侧抽屉（基础信息/产品参数/厂商信息，重置/确定）。
  - 列表：vxe-table；工具栏右圆形图标簇末项为字段管理（`icon-ziduanguanli`）。
  - 列设置：右侧抽屉约 514px，标题「勾选您要显示的字段」，工具「设置全部显示 / 排序整理 / 恢复系统默认」，底栏关闭/保存。
  - 添加产品：订货详情工具栏「+ 添加产品」；进行中常 `disabled`。草稿可开：**居中 Modal**（约 916×744），标题「添加产品」；页签单个产品/组合资料/客户产品/客户专属；关键词+出厂价区间+查询；旁路按编号列表/按出厂货号查询；主操作「批量提交选中产品（N）」；无底栏确定；表含图片/编号/名称/货号/客户货号/出厂价/进货价/标贴费/起订量/分类编号；底部分页。
- **可复用规则**：列设置与列表「产品查询」用右侧抽屉；单据「添加产品」用居中弹窗，不要互相套用。
- **可信度**：高（现网多页直接观察）。
- **待确认**：组合资料/客户产品/客户专属三个页签内的列与查询是否与「单个产品」相同；按编号列表/按出厂货号查询的二次弹层形态。

## E-006｜贸易端首页 + 产品资料全量实勘（2026-09-10）

- **来源**：登录态 Playwright 只读对照 `https://trade.tsbsoft.com`，覆盖 `/tsHome`、`/tsProductInformation`、`/tsImportProduct`，含全部弹层（综合查询、新建/编辑、图搜、列设置、更多操作、行更多、删除确认）与计算样式。采集原始件在 `08-自动化/playwright-tools/output/`（gitignored）。
- **观察（计算样式，运行态权威，覆盖 S-001 源码值的冲突项）**：
  - 壳：侧栏宽 210、底 `#333744`、logo 区高 60；**顶栏高 60（旧规范 50 作废）**；多页签条 40；一级菜单高 50、文字 15px，二级高 40、文字 14px、左缩进 48；未激活字 `#c6c6c6`，激活整行主色实底白字。
  - 白卡：圆角 6、阴影 `0 3px 6px rgba(0,0,0,.05)`、内边距 15px 20px、卡间距 15；卡标题 18px/700/`#333`。
  - 控件：输入/按钮高 32、圆角 4、文字 14；主色 `#009dff`；**成功 `#67c23a`、危险 `#f56c6c`（与 S-001 源码盘 #00b56a/#ff6624 冲突，运行态优先，待研发确认）**；遮罩 `rgba(0,0,0,.5)`。
  - 表格（vxe）：表头 40/700/`#333`/14，表体行 40/14，行 hover 浅蓝；操作列固定右侧。
  - 状态页签（el-tabs）：项高 50，激活下划线 2px；**激活色实测 `#409eff`，与主色 `#009dff` 不一致（待确认以哪个为准，原型暂统一主色）**。
  - 产品资料：状态页签 草稿/单个/组合/客户专属/全部；关键字框 250，append 为字段查询图标 + 精准查询勾选；工具条右 7 个 34px 圆形图标；分页「共 N 条记录 + 100条/页 + 页码 + 前往 N 页」。
  - 弹层尺寸：综合查询抽屉 850（分组 基础信息/产品参数/厂商信息/其他信息，两列）；新建/编辑弹窗 1400 近全屏、左 7 锚点、三列栅格；图搜浮层 706；列设置抽屉 710、61 字段四列 chip；删除确认无图标、标题正文居中、确定红色。
  - 导入产品为独立路由页（非弹窗），工具按钮 8 个、14 列空表、综合校验 7 项默认勾选、导入设置为下拉（采集到「新增模式：导入时系统自动生成产品编号，不受表格填写影响」）。
  - 菜单树 14 个一级（含旧规范缺失的「数据分析」：报价/销售/出货/采购/收货数据）。
- **可复用规则**：本批数值已同步 tokens.css；组件片段见 `组件/snippets/01～12`（与 `03-产品工作/现网页面复刻原型/组件/snippets/` 双写一致）。
- **可信度**：高（运行态 DOM + getComputedStyle + 截图三对照）。
- **待确认**：见「共性待确认」新增三条。

## S-001｜前端全局样式（代码）

- **来源**：`01-原始文件（Raw）/style/`（前端开发提供，2026-08-25）。入口 `index.scss`，主题 `theme.scss`，表格 `system.scss`，侧栏 `sidebar.scss`，重置 `reset.scss`。缺引用文件 `tsb/style`。
- **观察**：主色 `#009dff`；成功 `#00b56a`；警告 `#ff7c00`；危险 `#ff6624`；正文字 `#333`；微软雅黑；页面最小宽 `1400px`；侧栏默认底 `#333744`、宽 `210px` / 收起 `54px`；`erp-table` 表头约 `28px`、行高约 `32px`；弹窗最小 `500px` / 宽版 `1000px`；分割线 `#e6eaf0`。
- **代码内不一致**：`erp-table .action-link` 使用 `#1890ff`（Ant Design 蓝），与主题主色 `#009dff` 不同。原型跟 `#009dff`。
- **可复用规则**：高保真 token 以本条为色板与壳层尺寸权威；页面结构对照 E-001～E-005。
- **可信度**：中（Raw 代码切片；`--el-color-primary` 未写在这 10 个文件里，运行时可能被 JS 主题覆盖）。
- **待确认**：贸易端实际启用的 `data-theme` 是否为 `:root` 默认（`#333744`）还是 `default` 皮肤（`#001529`）；`--el-color-primary` 的运行时值。

## 共性待确认

- 主题色是否支持租户级配置；运行时主色是否等于 S-001 的 `#009dff`。
- “审核中”紫色、`status_color_0/1/2`（`#fb5430` / `#83b503` / `#f59b22`）与业务状态的映射是否全系统统一。
- 抽屉与新页签的选用规则。
- 「添加产品」中组合资料/客户产品/客户专属页签、以及按编号列表/按出厂货号查询的二次界面。
- 无权限、加载失败、空态在现网中的实际文案与视觉。
- 现网 Element Plus Dialog 内容区内边距是否为 20px（原型 `--dyj-dialog-body-padding`）。
- 【E-006】状态页签激活色 `#409eff` 与主色 `#009dff` 以哪个为准。
- 【E-006】运行态成功/危险色（#67c23a/#f56c6c）与源码盘（#00b56a/#ff6624）以哪个为准。
- 【E-006】产品表默认列含「自定义价格」，但列设置 61 字段 chip 清单无该项；导入设置除「新增模式」外其余 7 个选项文案未采集。
