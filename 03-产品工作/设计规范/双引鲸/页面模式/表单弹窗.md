# 表单弹窗

**适用**：新增、编辑、维护资料等局部任务。先读 [证据与待确认](../证据与待确认.md#e-003编辑产品资料弹窗)。

## 原型结构

- 简单表单：居中弹窗、紧凑栅格、必填红星、底部“关闭 / 确定”。
- 内容区（`.dyj-modal-body`）padding **20px**，token `--dyj-dialog-body-padding`（与 `--dyj-space-xl` 同值）。**不是**查询条件行间距 `--dyj-filter-gap`（15px）。现网 Element Plus Dialog 内边距待对照。
- 复杂资料维护：可用左侧分组导航 + 右侧多分区表单；上传项可使用虚线加号占位。
- 提交、关闭、校验提示应可演示；不需要模拟真实保存请求。

## 原型边界

- 弹窗并非所有页面的默认承载方式；涉及跨页上下文或复杂流程时优先对照目标现网。
- 字段分组与必填性来自业务需求，不从 E-003 推断。
- 对照证据为 E-003。
