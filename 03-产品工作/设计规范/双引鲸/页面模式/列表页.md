# 列表页

**适用**：单据、资料、查询结果等全页列表。先读 [证据与待确认](../证据与待确认.md#e-001销售报价列表)。

## 原型结构

1. 全页原型使用 App Shell；局部嵌入页面不强制展示侧栏、顶栏和多页签。
2. 按业务需要排列：筛选区 → 操作工具栏 → 数据表 → 分页。
3. 编号、货号等可进入详情的主标识使用蓝色链接；操作列优先使用文字操作与“更多”。
4. 仅在目标页存在时增加状态页签、图片列、批量操作、右侧工具图标或固定操作列。
5. 查询区、表格、列设置优先引用 [组件库](../组件/README.md) 片段，不要另起筛选栏和列设置弹窗。

## 原型边界

- 表格列、筛选字段、状态及操作必须来自需求或目标页面，不得因模板示例自动补齐。
- 表格虚拟滚动、列设置、导出等交互只做演示入口；正式实现使用组件库能力。
- 对照证据为 E-001；任何偏离在原型 README 说明。
