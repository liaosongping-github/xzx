## 最短使用路径

1. 读本文并确定原型是全页、列表、详情、弹窗还是首页。
2. 全页先复制 [组件/snippets/全局壳.html](组件/snippets/全局壳.html)；列表再引用查询条件、列表、列设置；选品引用产品选择器。对照 [组件画廊](templates/组件画廊.html)。
3. 读对应的 [页面模式](页面模式/) 与证据编号；没有现网依据的差异标为“待确认”。
4. 引用 `shell.css` + `components.css`，只替换字段、状态和动作，禁止重画壳层。
5. 交付前完成 [交付检查清单](交付检查清单.md)。
